# 23. Mem4Act：长期机器人操作的固定大小潜在记忆

- 论文：[arXiv:2610.22323](https://arxiv.org/abs/2610.22323) · [官方 PDF](https://arxiv.org/pdf/2610.22323) · 本地 PDF：`2610.22323.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Yun Zhang、Zhiyu Huang 等；UCLA、North Carolina State University。**机构优先级 P2**。
- 主题：latent memory；long-horizon embodied agent；VLA。与文本 LLM 记忆**弱相关但具启发性**。证据范围：全文 23 页。

1. **做了什么（论文证据）**：提出为长时机器人操作训练固定规模潜在记忆，避免原始视频历史持续增大或文本摘要丢失动作相关细节。
2. **怎么做与实验（论文证据）**：多粒度时间聚合覆盖历史，问答监督保存语义、关键帧 DINO 特征重建保存感知细节，并以先训记忆后训策略促进动作模型真正依赖记忆；测 RoboMME、RMBench 和四项真实操作。
3. **结论（论文证据）**：作者报告记忆依赖控制上的领先表现，摘要给出 49.88%、61.0%、81.5% 等对应设置的成功率；消融显示时间聚合、互补监督和两阶段训练重要。
4. **未来影响（我的推断）**：潜在记忆不应只追求压缩率，还应通过下游行为检验“是否被策略使用”。
5. **Critical thinking**：不同基准成功率不能直接比较；需测任务变化、视觉遮挡、罕见安全状态、长期错误累积，以及同 token/存储预算的原始历史基线。
6. **可信度 3/5**：真实操作与组件消融是优点；对文本 LLM/用户个性化的迁移仍属于推断。
