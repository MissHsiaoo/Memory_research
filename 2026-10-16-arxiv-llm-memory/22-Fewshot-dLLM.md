# 22. 扩散语言模型的多目标少样本提示

- 论文：[arXiv:2610.22294](https://arxiv.org/abs/2610.22294) · [官方 PDF](https://arxiv.org/pdf/2610.22294) · 本地 PDF：`2610.22294.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Anton Xue、Alan Li、Rahul Saha；UT Austin。**机构优先级 P2**。
- 主题：diffusion LLM；in-context learning；multi-target infilling。证据范围：全文 33 页。

1. **做了什么（论文证据）**：让示例指导扩散语言模型一次画布中的多个掩码位置编辑，处理自动回归模型难利用右上下文的案例。
2. **怎么做与实验（论文证据）**：在指定目标位置做少样本提示，并通过选择性遮蔽构造示例支持的似然比奖赏，引导候选填充；评估少样本基准与软件重构案例。
3. **结论（论文证据）**：示例通常提升填充准确率，示例引导在部分设置进一步有效；摘要并未给出可概括到所有任务的单一收益数字。
4. **未来影响（我的推断）**：扩散 LLM 能把多个依赖左右文的示例编辑同时纳入 ICL；也可用于多处记忆修订，但本文未实测。
5. **Critical thinking**：作者假设目标位置和示例输出区域事先已知、目标长度预分配；确定性逐 token 精确评分未发挥扩散并行优势。应评测自动定位、长度变化和墙钟效率。
6. **可信度 3/5**：方法与案例实证完整；实际自动编辑流水线的前置定位/长度需求仍是主要障碍。
