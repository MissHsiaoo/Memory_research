# 6. Unmasking the Secret Code：训练记忆的“金丝雀”审计边界

- 论文：[arXiv:2610.20656](https://arxiv.org/abs/2610.20656) · [官方 PDF](https://arxiv.org/pdf/2610.20656) · 本地 PDF：`2610.20656.pdf`
- 公告：2026-10-16；初次提交：2026-10-13。
- 作者/机构：PDF 首页核验 Avi Schwarzschild、Om Thakkar、Sahra Ghalebikesabi、Congzheng Song、Vinnie Monaco；OpenAI。**机构优先级 P1**。
- 主题：memorization；privacy audit；SFT。**与长期 agent memory 弱相关但具启发性**。证据范围：全文 51 页。

1. **做了什么（论文证据）**：检验用含秘密的合成训练记录（canary）判断模型记忆/泄露时，结论如何依赖秘密呈现方式。
2. **怎么做与实验（论文证据）**：在文本与视觉语言模型上做受控 SFT，变化秘密是否已出现在输入、是否必须由上下文预测、重复次数、插入时间以及同批其他金丝雀，并分别测输入可复现与移除输入后的召回。
3. **结论（论文证据）**：单纯重复或训练时能复制秘密，并不保证移除上下文后仍能回忆；要求从周围上下文预测时，后续召回会变强。时间和同批样本也显著影响测量。
4. **未来影响（我的推断）**：参数化记忆或个性化微调的隐私评估不能只用单一 canary 设定，需匹配真实写入路径。
5. **Critical thinking**：训练阶段、优化过程和后续 RL 的交互仍未解决；合成秘密也不等于真实个人资料。建议设计跨阶段、多位置、多共现条件的审计矩阵。
6. **可信度 4/5**：受控因素多、模型形态覆盖广，论证了审计敏感性；但这不是 agent 外部记忆系统的效果实验，不能直接外推其检索/删除机制。
