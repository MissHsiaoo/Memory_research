# 4. LoCD：从交互经验做局部上下文蒸馏

- 论文：[arXiv:2610.21427](https://arxiv.org/abs/2610.21427) · [官方 PDF](https://arxiv.org/pdf/2610.21427) · 本地 PDF：`2610.21427.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Zhezheng Hao、Yongkang Yang 等；浙江大学、Tencent Workbuddy Team、香港中文大学、香港科技大学。**机构优先级 P1**。
- 主题：interaction experience；context distillation；continual improvement。证据范围：全文 26 页。

1. **做了什么（论文证据）**：提出 Localized Context Distillation，让学生从交互经验中学会新行为，同时避开离策略教师轨迹的曝光偏差。
2. **怎么做与实验（论文证据）**：定位学生轨迹中需修正的关键片段；教师基于学生已有前缀只重生这些片段，学生只对局部改写学习。在数学推理、代码生成、agent 任务与离策略/在策略蒸馏基线比较。
3. **结论（论文证据）**：作者报告稳定训练、较小且稀疏的参数更新，并持续胜过所测基线；这属**把经验蒸馏到参数**，并非外部可检索记忆系统。
4. **未来影响（我的推断）**：agent 经验写入可采用“局部错误修复”，避免完整轨迹重训造成无关行为漂移。
5. **Critical thinking**：错误定位器是关键假设，定位遗漏可能学不到新行为。应在偏好矛盾、未见工具、新环境和同计算预算下比较全轨迹与局部蒸馏。
6. **可信度 3/5**：多个任务域与明确机制是优点；实际长期学习、遗忘与误定位代价需额外验证。
