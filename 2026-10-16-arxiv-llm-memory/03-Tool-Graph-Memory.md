# 3. Rethinking the Role of Tool Graph Memory：工具图记忆是否真的有用

- 论文：[arXiv:2610.21571](https://arxiv.org/abs/2610.21571) · [官方 PDF](https://arxiv.org/pdf/2610.21571) · 本地 PDF：`2610.21571.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Uiji Hwang、Richeng Xuan、Taeuk Kim；汉阳大学、Tencent Hunyuan。**机构优先级 P1**。
- 主题：agent memory；tool graph；causal evaluation。证据范围：全文 14 页。

1. **做了什么（论文证据）**：重新检验“保存工具转移图可改善多轮工具使用”这一假设，比较图建议、随机/无建议和文本经验。
2. **怎么做与实验（论文证据）**：九个模型、两个基准，报告显著性、调用次数和失败类型；把同一经验改写为文本 insight，控制记忆内容而比较呈现形式。
3. **结论（论文证据）**：工具图很少显著优于基线；有收益时往往消耗超过两倍 LLM 调用。随机或无图建议保留大部分收益，文本 insight 反而更好且调用增量小。
4. **未来影响（我的推断）**：经验记忆更适合作为软先验，而不是把过去的下一工具当作硬指令。
5. **Critical thinking**：作者只研究节点是工具、边是转移的图，不可概括到含状态、参数和结果的所有图记忆。应补充等调用预算、跨工具注册表变化及长期运行的对照。
6. **可信度 4/5**：多模型、成对对照和成本分析支撑负结果；图结构范围有限，仍需实测更丰富的过程图。
