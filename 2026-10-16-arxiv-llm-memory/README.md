## 机构分布与主题趋势

- 按**论文优先级**计：P1 7 篇，P2 18 篇；未为补足数量加入低机构优先级的“黑马”。P1 中 Tencent 参与 3 篇、Alibaba 2 篇、OpenAI 1 篇、Meta 1 篇；跨机构论文在此按参与情况归类，不将共同署名误当独立篇数。P2 主要由 Stanford、CMU、UIUC、UC 系高校、MIT、Mila、国内重点高校和产业研究团队贡献，逐篇机构以 PDF 首页和独立笔记为准。
- 记忆研究由“检索更多”转向**写什么、什么时候写、怎样用以及何时删**：Hy-Memory、MemComposer、RIKA、MemCut 分别覆盖写入、组合、准入和删除；Librarian Agents 把组织记忆提前到问题出现前。
- **自进化不等于稳定增益**：技能—策略共同更新的漂移风险与 Tool Graph Memory 的受控反证，都提示要报告负结果、长程反馈与真正的组件增益，不能只看最终问答分数。
- **潜在／参数记忆、个性化、扩散 LLM** 分别呈现压缩状态、流数据权重更新、用户路由以及解码/提示策略的探索，但任务和基线差异大，不能跨论文直接比较分数。少数宽方向论文保留为跨领域启发，已逐篇标示边界。

## 最值得深读的 3 篇

1. [Hy-Memory-30B-A3B](01-Hy-Memory.md)：重点机构且直击长期记忆写入；跨框架训练与留出框架设计值得复现。其领先幅度很小、仅用固定 20% 子集，尤其需要核查统计稳健性。
2. [Memorilla](08-Memorilla.md)：把历史压到固定 token 预算的潜在状态，最贴近 latent memory 问题；应重点看预算—性能曲线、刷新机制与跨任务迁移。
3. [Evolving Together, Failing Apart](02-CoEvo-Trap.md)：指出自进化 agent 的技能与策略可能相互污染；读它可为持续记忆系统设计漂移检测、反事实评估与回滚机制。
