# 14. RIKA：给持续学习 agent 的经验设准入门槛

- 论文：[arXiv:2610.21739](https://arxiv.org/abs/2610.21739) · [官方 PDF](https://arxiv.org/pdf/2610.21739) · 本地 PDF：`2610.21739.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Yixu Huang（UC Davis）、Jiaqi W. Ma（UIUC）。**机构优先级 P2**。
- 主题：continual agent learning；knowledge admission；negative transfer。证据范围：全文 23 页。

1. **做了什么（论文证据）**：提出 RIKA，对 agent 从经验中提取的事实、概念、程序、元认知知识设置证据驱动的准入，而非所有生成经验都复用。
2. **怎么做与实验（论文证据）**：分层抽取知识，结合原始证据与随后经验判断是否允许进入任务上下文，不增加专门验证任务；六个持续学习任务流、四种底座比较代表系统。
3. **结论（论文证据）**：作者发现对照系统约 12–33% 经验条目会伤害后续任务；RIKA 在四种底座上均取得最高汇总分。
4. **未来影响（我的推断）**：写记忆不应等同立即信任；可形成待验证、证据充分、已废弃等状态生命周期。
5. **Critical thinking**：准入可能过保守，错失罕见但有价值的新经验。应报告覆盖率—误收率曲线，测试感知/物理反馈、来源对抗与多用户隔离。
6. **可信度 4/5**：负迁移有显式测量，多流多底座支持主张；作者指出任务仍是文本工具环境，未证明具身或开放世界迁移。
