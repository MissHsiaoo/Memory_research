# 5. MetaExp：跨任务学习“如何利用经验”

- 论文：[arXiv:2610.21492](https://arxiv.org/abs/2610.21492) · [官方 PDF](https://arxiv.org/pdf/2610.21492) · 本地 PDF：`2610.21492.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Renhao Li、Xinjie Shen 等；澳门大学、Georgia Tech、Alibaba Token Hub、深圳先进技术研究院。**机构优先级 P1**。
- 主题：self-evolving agent；experience learning；cross-task transfer。证据范围：全文 18 页。

1. **做了什么（论文证据）**：试图把经验学习本身训练成可迁移模型能力，而不是只优化某个任务分布的外部经验提示。
2. **怎么做与实验（论文证据）**：构造共享工具与共享工作流的可验证任务家族，保留可复用因素而更换任务具体实现；从 1000 家族选取 4956 条顺序轨迹，微调 Qwen3.5-122B-A10B，部署评估时冻结参数并允许非参数经验积累。
3. **结论（论文证据）**：论文报告 SpreadsheetBench +8.5 点、APEX-Agents 峰值 +2.3 点、AutomationBench +14.8 点；排除目标领域的训练仍有收益。
4. **未来影响（我的推断）**：可把“识别何种经验值得保留”作为模型基础能力，与可解释的外部记忆库结合。
5. **Critical thinking**：任务家族的人为共享结构可能让迁移比真实世界容易；建议与等算力多任务训练比较，测完全异构工具、负迁移和长期经验污染。
6. **可信度 3/5**：多基准与领域排除测试有说服力；仅一个大型底座与构造型任务家族，真实开放部署的外推有限。
