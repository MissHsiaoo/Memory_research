# 1. Hy-Memory-30B-A3B：跨框架的长期记忆写入模型

- 论文：[arXiv:2610.22196](https://arxiv.org/abs/2610.22196) · [官方 PDF](https://arxiv.org/pdf/2610.22196) · 本地 PDF：`2610.22196.pdf`
- **公告批次**：2026-10-16（北京时间 10 月 16 日核验）；**初次提交**：2026-10-15，不能以提交日期代替公告日期。
- 作者/机构：PDF 首页核验 Tianxiang Fei、Jiazheng Kang、Mao Zheng、Xingyan He、Xiang Yu；Tencent Hunyuan。**机构优先级 P1**（用户指定重点机构）。
- 主题：LLM long-term memory；memory writing；RL。证据范围：官方 PDF 全文 15 页的方法、实验及局限；下述“未来影响”与批评是本报告推断。

1. **做了什么（论文证据）**：训练专用记忆写入模型，在 Mem0、MemOS、Hy-Memory 三种框架下决定保留、表达和更新持久状态，而非每套框架依赖通用大模型提示词。
2. **怎么做与实验（论文证据）**：先对学生模型生成的状态做 Memory On-Policy Distillation，再用跨片段归因奖赏、过量存储惩罚及片段级 GRPO 做 Memory RL；跨时间窗保留策略自行写的记忆库。固定的 20% 基准子集涵盖四个 harness，包括未见过的 EverMemOS。
3. **结论（论文证据）**：作者报告四个 harness 均排名第一，宏平均 55.49%，对照 Claude Opus 5 的 54.62%。论文自己指出这一差距很小，0.01–0.02 点级别差异不具统计显著性。
4. **未来影响（我的推断）**：记忆写入策略可能成为可迁移的独立模型层，系统可将“写入能力”与“回答能力”拆开优化。
5. **Critical thinking**：奖励来自证据归因而非真正反事实，不能证明某次写入导致正确答案。建议全量测试、多个训练种子、更多未见框架，并测错误记忆纠正、删除请求和写入成本的质量—延迟曲线。
6. **可信度 3/5**：有跨框架与留出框架实验，训练链条清楚；但主结果只用确定性 20% 子集、优势幅度很小且未报重复训练方差。机构优先级与此证据分数独立。
