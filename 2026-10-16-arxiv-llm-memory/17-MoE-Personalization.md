# 17. MoE 个性化：哪些专家承载用户特征

- 论文：[arXiv:2610.22127](https://arxiv.org/abs/2610.22127) · [官方 PDF](https://arxiv.org/pdf/2610.22127) · 本地 PDF：`2610.22127.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Sekh Mainul Islam、Pepa Atanasova、Isabelle Augenstein；哥本哈根大学。**机构优先级 P2**。
- 主题：LLM personalization；MoE latent features；interpretability。证据范围：全文 16 页。

1. **做了什么（论文证据）**：研究个性化 MoE LLM 中哪些专家和潜在特征编码用户适配行为，而非只报告最终个性化分数。
2. **怎么做与实验（论文证据）**：在大规模个性化数据上适配三个开源 MoE，比较非个性化/个性化模型激活，训练 crosscoder 找潜在特征，再做专家路由与潜在特征的因果干预。
3. **结论（论文证据）**：个性化 MoE 与稠密模型效果可比却只激活部分参数；识别出的潜在特征和关联专家干预能把原模型行为推向个性化模型。
4. **未来影响（我的推断）**：若特征可可靠定位，未来或能对用户偏好做局部、可解释的更新；目前不能据此宣称可安全删除特定偏好。
5. **Critical thinking**：作者每模型主要分析一个按路由差异选取的层，可能遗漏其他层；应测多层、共享专家架构、真实用户偏好变化与隐私隔离。
6. **可信度 3/5**：三模型与干预比纯相关分析更强；层选择和模型家族范围限制机制泛化。
