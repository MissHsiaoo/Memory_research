# 2. Evolving Together, Failing Apart：技能—策略共进化的漂移陷阱

- 论文：[arXiv:2610.20845](https://arxiv.org/abs/2610.20845) · [官方 PDF](https://arxiv.org/pdf/2610.20845) · 本地 PDF：`2610.20845.pdf`
- 公告：2026-10-16；初次提交：2026-10-14。
- 作者/机构：PDF 首页核验 Yujie Feng、Xiaobin Wang 等；Alibaba Token Hub / Alibaba Group、香港理工大学、UIC。**机构优先级 P1**。
- 主题：self-evolving agent memory；skill bank drift；evaluation。证据范围：全文 35 页。

1. **做了什么（论文证据）**：指出共同进化的 agent 策略只在交付时的技能库上评测，部署后技能改写/增删会让策略失配；提出 CODA 漂移审计。
2. **怎么做与实验（论文证据）**：理论分析合作式接受规则对固定技能库的依赖，再模拟含义保持的改写和受损技能，对四种共进化方法、五基准六设置测试峰值、最坏漂移、语义一致率与抗污染率。
3. **结论（论文证据）**：最坏漂移成功率比交付组合的峰值低 5–13 点，抹去相对无技能基线收益的 52–93%。作者强调这是诊断及评估协议，并未提供修复算法。
4. **未来影响（我的推断）**：自进化记忆应评价“库持续变化时策略能否适应”，而非只评价最终快照。
5. **Critical thinking**：模型重写技能并非完全可复现，且同模型家族改写可能低估脆弱性。建议跨模型独立改写、人类真实编辑、长期上线序列和等成本修复策略对比。
6. **可信度 4/5**：理论与跨方法实证互补，提供了可复用审计；局限是模拟漂移分布与真实部署未必相同，且尚未解决脆弱性。
