# 15. MemCut：长期 agent 记忆中的秘密能否真的删掉

- 论文：[arXiv:2610.21405](https://arxiv.org/abs/2610.21405) · [官方 PDF](https://arxiv.org/pdf/2610.21405) · 本地 PDF：`2610.21405.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Cheng Zhang、Xuanning Cao、Zhicheng Zheng、Hui Xiong；香港科技大学（广州）、中国科学技术大学、香港科技大学。**机构优先级 P2**。
- 主题：personalized memory privacy；forgetting；agent memory benchmark。证据范围：全文 17 页。

1. **做了什么（论文证据）**：提出用户要求遗忘时的系统性基准 MemCut，检测秘密在长对话的派生证据中是否残留。
2. **怎么做与实验（论文证据）**：456 个手工秘密及完整证据轨迹，区分正常检索可恢复的 native recovery 与直接给存活对象的 residual recovery；比较三类删除基线、五种记忆设计、四个 LLM。
3. **结论（论文证据）**：只删除直接披露，native recovery 降幅远大于 residual；在额外 20 个候选中由 LLM 选删 10 轮，仍有 39–76% 残余可恢复。候选覆盖是瓶颈之一。
4. **未来影响（我的推断）**：个性化记忆删除需要证据图级清理、派生事实追踪和残余恢复测试，而非只删单条原文。
5. **Critical thinking**：控制式秘密与真实复杂个人信息不同；应测跨库备份、模型内部更新、语义重述和用户可验证删除证明。
6. **可信度 4/5**：多设计/模型与双恢复指标切中真实风险；论文只证明所构造长对话证据轨迹的参考删除失效，不代表所有部署的隐私泄露率。
