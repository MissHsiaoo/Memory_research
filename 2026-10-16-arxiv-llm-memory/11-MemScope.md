# 11. MemScope：局部代码修复驱动记忆架构自进化

- 论文：[arXiv:2610.21170](https://arxiv.org/abs/2610.21170) · [官方 PDF](https://arxiv.org/pdf/2610.21170) · 本地 PDF：`2610.21170.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Miao Su、Yucan Guo 等；中科院计算所/国科大/AI 安全重点实验室、美团。**机构优先级 P2**。
- 主题：self-evolving agent memory architecture；code repair；trace evidence。证据范围：全文 19 页。

1. **做了什么（论文证据）**：让 agent 的记忆系统本身随任务反馈修改，但限制为有证据支撑的局部原位代码修复。
2. **怎么做与实验（论文证据）**：Patch Agent 联合看原始执行轨迹、运行时记忆状态与当前架构代码，定位失败并受提供者身份和记忆兼容性约束；在 GAIA、xBench、ALFWorld 及历史快照转移上测试。
3. **结论（论文证据）**：GAIA 的轨迹+记忆检查为 86.67%，对比仅轨迹 70%、仅摘要 63.33%；ALFWorld 未见任务成功率 50.75→71.64%，存档转移代码改动中位数 4.4%。
4. **未来影响（我的推断）**：记忆架构可以从可定位错误中渐进修补，减少反复整体替换带来的回归风险。
5. **Critical thinking**：修补成功依赖失败证据与回归测试覆盖；应在权限/隐私规则、并发写入、错误归因误导和长周期多轮修复下验稳定性。
6. **可信度 4/5**：多环境、反馈粒度消融和改动范围量化充分；真实生产记忆迁移与安全约束仍需验证。
