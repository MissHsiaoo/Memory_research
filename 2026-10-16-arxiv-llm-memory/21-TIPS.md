# 21. TIPS：扩散 LLM 中可重遮蔽的轻量解码策略

- 论文：[arXiv:2610.22099](https://arxiv.org/abs/2610.22099) · [官方 PDF](https://arxiv.org/pdf/2610.22099) · 本地 PDF：`2610.22099.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Ya-Shi Zhang、Jian Tang 等；ServiceNow AI Research、Mila、HEC Montréal。**机构优先级 P2**。
- 主题：diffusion LLM；inference-time policy；revision。证据范围：全文 50 页。

1. **做了什么（论文证据）**：训练约 60 万参数的小控制器，决定扩散去噪每步哪些 token 可见，并允许重新遮蔽，冻结主解码器。
2. **怎么做与实验（论文证据）**：用可见性相关置信度特征和浅 Transformer，先监督热身再用最终正确性奖赏做 RL；在 LLaDA-8B-Instruct 的 GSM8K、MATH-500 上按相同 32 次 decoder evaluation 比较。
3. **结论（论文证据）**：全画布/双块版本微平均正确率 58.46%/57.97%，比论文主对照最强者高 12.1/11.6 个百分点；更高调用预算下不重训仍有竞争力。
4. **未来影响（我的推断）**：让模型保留“可修订”状态可能比单调解码更有效，也启发可撤销的记忆写入策略。
5. **Critical thinking**：作者主要测 256-token 数学推理，固定解码长度与 decoder 调用数不等于真实墙钟成本；应测更长生成、多任务、多种底座及自适应停止。
6. **可信度 3/5**：预算匹配与干净控制器设计是优点；补充迁移仅单种子、任务范围窄。
