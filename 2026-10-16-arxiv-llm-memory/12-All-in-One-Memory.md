# 12. All-in-One Memory：检索、写入、停止的过程奖赏

- 论文：[arXiv:2610.21147](https://arxiv.org/abs/2610.21147) · [官方 PDF](https://arxiv.org/pdf/2610.21147) · 本地 PDF：`2610.21147.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Bingbing Wang、Jingjie Lin 等；哈工大深圳、香港理工大学、复旦大学、鹏城实验室。**机构优先级 P2**。
- 主题：LLM memory agent；process reward；evidence tracking。证据范围：全文 26 页。

1. **做了什么（论文证据）**：提出 AiO-Mem，将检索、写记忆和停止视为共享证据状态上的动作，用统一过程奖赏训练。
2. **怎么做与实验（论文证据）**：先把历史编成可追源多视图事件；统一策略完整展开记忆交互轨迹，另训轨迹条件过程奖赏模型，以证据监督微调和轨迹级 DPO 学评分，再用 action-balanced reward 与 PA-DAPO 优化策略。
3. **结论（论文证据）**：在所测长上下文记忆基准上，作者报告答题准确率优于静态记忆系统和 RL 训练记忆 agent；具体幅度应按任务表逐项看，不能概括为普遍最优。
4. **未来影响（我的推断）**：过程级评价可区分“答对了但写入错误”与真正可靠的记忆操作。
5. **Critical thinking**：奖赏模型可能继承证据标注偏见，检索/写入/停止的平衡权重敏感。应测来源伪造、错写回滚、跨域任务、长期库增长及与等算力简单基线比较。
6. **可信度 3/5**：有明确统一动作空间与完整训练链；论文标注 work in progress，外部复现与真实长时运行尚待验证。
