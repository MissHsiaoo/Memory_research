# 10. MemComposer：学会选择、数量和排序记忆

- 论文：[arXiv:2610.21091](https://arxiv.org/abs/2610.21091) · [官方 PDF](https://arxiv.org/pdf/2610.21091) · 本地 PDF：`2610.21091.pdf`
- 公告：2026-10-16；初次提交：2026-10-15。
- 作者/机构：PDF 首页核验 Yixuan Xie、Xueqiang Xu 等；UIUC、Amazon。**机构优先级 P2**。
- 主题：agent memory assembly；retrieval-memory；RL。证据范围：全文 30 页。

1. **做了什么（论文证据）**：不改变底座 agent 权重，学习针对当前查询如何从候选经验中选、选多少、以何顺序呈现。
2. **怎么做与实验（论文证据）**：ExPO 用类似 GRPO 的训练，完整 agent 交互任务成功反馈作为上下文组合奖赏；在三个 τ²-bench 领域、两个冻结执行器上比较最强记忆基线，并测 token 成本与迁移。
3. **结论（论文证据）**：两个执行器均优于各自最强基线，平均记忆 token 用量分别少 16.9% 和 4.9%；作者报告向未见领域、执行器及记忆库迁移。
4. **未来影响（我的推断）**：检索排序可升级为下游结果驱动的“记忆编排策略”，与写入策略分离优化。
5. **Critical thinking**：优化任务成功可能偏好短期捷径或错误经验。应测固定 token/调用预算、经验污染、不同执行器偏好差异和长时训练漂移。
6. **可信度 4/5**：冻结执行器和跨设置实验强化因果归因；作者也承认尚未充分解释强弱执行器偏好何种记忆形态。
