# 05. RIME

- 论文：**Remember by Asking: Retrieval-Induced Memory Evolution for LLM Agents**
- arXiv：[2609.34438](https://arxiv.org/abs/2609.34438)；[官方 PDF](https://arxiv.org/pdf/2609.34438)
- 提交日期：2026-09-28；正式公告批次：2026-09-29（北京时间）
- 作者/机构（官方全文首页核验）：JD.com、Chang'an University
- 机构优先级：**A｜大型工业研究机构**
- 研究标签：memory evolution、retrieval feedback、agent memory、self-evolving agent
- 证据范围：已阅读官方全文 HTML；本地 PDF 下载超时。

## 1. 做了什么

RIME 让记忆在被查询和使用后继续演化：检索不是只读操作，而是暴露缺口、冲突和冗余，并反向驱动 memory 更新。

## 2. 怎么做、实验如何设计

框架记录检索命中、后续推理和任务结果，把失败查询转化为针对性的记忆重构信号；其核心区别是更新由“真实使用需求”触发，而不是周期性全库摘要。论文在多类 agent 任务上与静态存储、纯反思和常规检索增强基线比较，并分析多轮演化趋势。

## 3. 结论

有价值的长期记忆不是一次写成的；查询分布本身提供了最直接的维护信号，可让存储逐步贴合未来任务。

## 4. Future impact

对于个人助手，RIME 类机制可把用户反复追问、纠错和检索失败转化为画像与证据索引的持续改进。

## 5. Critical thinking

关键风险是反馈回路：错误检索可能促成更错误的更新，热门查询也会挤压冷门但重要的事实。应增加版本化、冲突检测、不可变原始证据和反事实检索评估，并区分“用户真实偏好变化”与“模型此前理解错误”。

## 6. 可信度判断

**3.8/5。** 问题定义新颖且直接相关，全文提供实验与演化分析；但长期累积误差、记忆污染和跨分布查询仍需更长时间尺度验证。
