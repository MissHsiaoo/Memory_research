# 04｜EchoPath: Execution-Level Replayable Memory for GUI Agents

- 来源：[arXiv v1](https://arxiv.org/abs/2609.16635v1) · [官方PDF](https://arxiv.org/pdf/2609.16635v1) · [本地PDF](../papers/2609.16635.pdf)

## 1. 做了什么

把成功的GUI交互轨迹保存成可再次调用的执行记忆，而不只是给LLM看的文字经验。记忆包含意图、前置条件、可替换参数、视觉定位及生命周期信息，调用时先检查环境，再重定位与重放，失败则退回完整推理。

## 2. 怎么做，实验如何设计

两遍OSWorld流程：第一遍执行任务并构建成功轨迹库，第二遍在屏幕分辨率从1920×1080变为1600×900后重放同一批任务。关键分母是第一遍成功后留下的159条active executable memories，并非所有OSWorld任务。比较多模型重放和Synapse类完整推理：Codex GPT-5.5在159条上145次成功，即91.2%；中位输入/输出相关token统计20370，时间127.5秒；Synapse成功率91.8%，中位token586386、315.7秒。建库本身中位约572K token、4.5分钟，必须单独计入。

组件测试包括200个视觉目标的重新定位、从159扩大到659记忆的检索干扰、50个错误起始环境及参数替换案例。视觉测试主要是在保存图像上做缩放；检索探针来自存储意图，参数合法性测试包含离线/合成环节，不是所有变体都经过真实GUI闭环。

## 3. 结论

直接证据：对已成功、重复出现且界面变化有限的任务，可在接近成功率下大幅节约再次推理成本。不是证明开放世界新任务也达到91.2%。错误起始状态50例中拒绝39例，意味着仍有11例被放行；安全门不能视为已解决。

## 4. Future impact：未来影响

我的推断：这类记忆更接近“可执行程序+适用条件”，适合高频桌面工作流。记忆系统的新研究对象可以是技能的适用域、版本迁移与失效检测，而不是向量检索命中率。与自然语言记忆结合时，文字负责解释和审计，执行表示负责低成本动作复用。

## 5. Critical thinking：批判性分析

首轮成功条件化和同任务二次测试明显有利于重放；需要新意图、新布局、弹窗、异步加载和任务步骤变化。建库成本应摊销：多少次复用后才比每次重规划便宜？检索100%并不等于陌生用户自然表述下100%。起始gate的22%错误状态放行尤其需要动作前检查与执行后验收。

建议按UI漂移强度绘制成功率，设置从未见过的模板与参数组合，并统计失败动作的可逆性。以前保存的操作轨迹不应携带永久授权：付款、发送、删除等动作每次仍需匹配当前用户意图和权限。

## 6. 可信度、优点与局限

3.5/5。优点：真实GUI执行、明确成本比较、检索/定位/门控拆解，有直接工程价值。局限：选择偏差、重复任务协议、有限变化类型，以及安全门误放行；部分鲁棒性测试不是完整线上执行。已读方法与组件评估，未独立运行OSWorld。置信度针对受限场景的复用收益，不针对通用GUI自动化安全。
