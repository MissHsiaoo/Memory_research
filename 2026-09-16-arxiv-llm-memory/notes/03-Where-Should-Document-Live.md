# 03｜Where Should a Document Live: Context, Representations, or Parameters?

## 1. 做了什么

直接比较一份文档应存在哪里：原始上下文、压缩KV表示，还是模型参数/adapter。它不是提出一个包打天下的memory模块，而是把存储预算、单文档问答、多文档组合及原有能力干扰放在同一框架中，非常适合作为latent memory研究的实验设计参考。

## 2. 怎么做，实验如何设计

主干Qwen3-8B，附录补Gemma3-12B。五个数据集为LongHealth、QASPER、QuALITY、FinQA、TechQA，覆盖医疗、论文阅读、长文选择题、财务公式和技术问答；分别使用相应Accuracy/F1/EM或LLM判分，不把不同指标误说成统一准确率。用共同的self-study数据比较Cartridges学习KV、Compaction、LoRA、残差MLP adapter及全参数微调，按文档大小匹配存储，扫2、10、20、50、100倍压缩，受最小rank限制并非每种方法都覆盖全部倍率。报告3次运行。

表2在2倍压缩下的跨任务均分：无上下文24.9、ICL73.6、Cartridges70.6、Compaction73.4、LoRA64.5、MLP62.2、全微调59.8。多文档实验检索top-k，将KV拼接、参数adapter求平均，也比较联合训练adapter。Cartridges在LongHealth从k=1的70.8升到k=10的83.2；Compaction从72.9降到56.3。

## 3. 结论

证据支持：低压缩单文档下Compaction很强；压缩更重或需要组合多文档时，学习的Cartridges更稳定。参数注入在当前设置中更容易损失任务外能力，简单平均adapter易受干扰。不能将这一结果扩大为所有参数记忆不可组合，或所有文档都应只存KV。

## 4. Future impact：未来影响

我的推断：面向个人记忆可以建立分层存储：原文保留可溯源证据、KV承载高频可组合知识、参数只吸收稳定技能。真正有价值的后续问题是存储位置如何随更新频率、删除要求和查询负载动态变化，而不是仅比较一次性QA得分。

## 5. Critical thinking：批判性分析

公平性重点：匹配存储字节不等于匹配训练时间、推理成本或维护成本；KV拼接与LoRA平均是不同性质的组合操作，失败可能来自合并算子，而非参数介质本身。应补路由式adapter、组合时重训练、逐文档选择等更强基线。self-study合成数据的覆盖与质量也可能主导结果。

论文将外部表示启用时的能力下降也放入forgetting讨论，但冻结底模的KV干扰与永久权重遗忘应分开，需报告卸载记忆后能力是否恢复。建议加入用户事实更新、冲突文档、授权撤回和记忆删除，比较每次写入/读取成本与累计效益。

## 6. 可信度、优点与局限

4/5。优点：同一数据生成框架、存储匹配、多数据集、多文档与能力干扰测量，证据比单一榜单充分。局限：仅两个中等规模模型，参数组合基线有限，知识问答不等于技能学习，完整生命周期成本尚不充分。阅读了方法、主表、多文档结果及局限；未重新训练，因此将结论限定于作者实现与测量范围。
