# 09｜Verbalizing Subliminal Learning Effects Using Text Optimization

## 1. 做了什么

尝试把训练数据里难以从表面看出的隐性偏好转成可读文本。例如教师只生成数字串，但其偏好仍可能通过统计模式影响学生；SALVE寻找能够解释这种数据分布的文字提示，而不是声称还原唯一的原始系统提示。

## 2. 怎么做，实验如何设计

先针对数据负对数似然优化soft prompt，再由同一LLM将连续提示 verbalize 成文字，配合beam search选择候选。主受控实验用Qwen2.5-7B，教师分别偏好cat/dog/eagle/owl，每种生成10K数字序列；500条保留用于NLL评估，256条训练子集用于候选评分，每种动物5个种子，共20次。比较GCG、AutoDAN、LARGO、best-of-N等，并扩展到混合数据、激活steering以及偏好筛选数据。

主表SALVE NLL为0.437，参考提示0.410、空提示0.523；识别动物18/20。必须注意best-of-N同样18/20，NLL0.441；SALVE的优势并不是主任务识别率上独占领先。部分基线如OPRO涉及外部API，计算预算比较需谨慎。

## 3. 结论

直接证据：某些不可直接读出的数据特征可通过模型自身的分布敏感性转换为可理解的描述。优化出的提示能解释或复现数据特征，但不等于证明真实数据源具有某种意图，也不等于任何训练学生都一定学到该偏好。

## 4. Future impact：未来影响

我的推断：适用于个性化memory训练前的数据审计——压缩后的用户样本、合成反馈、经验回放库可能携带非目标偏好。若能发现这些偏好，就能在持续更新前做人类可读的检查。更有挑战的方向是对latent memory槽位做类似语义审计，同时验证解释忠实性。

## 5. Critical thinking：批判性分析

优化NLL可能捕捉模型自身偏好或数据表面规律，并生成看似合理的故事。主实验偏好类别清楚且选择有限，现实个性化可能多维、冲突且没有唯一文本描述。最佳候选选择和beam搜索增加成本，需与简单best-of-N在预算匹配后比较。

建议加入无偏好负例、弱信号剂量曲线、未知类别和跨家族教师-审计器组合，测假阳性；再训练独立学生验证被 verbalize 的属性是否真会转移。对真实用户数据不要把“模型读出的心理特征”当事实。

## 6. 可信度、优点与局限

4/5。优点：可控制教师偏好、清晰优化目标、多种解释/搜索基线，能用预测似然检验而不只展示文字案例。局限：主任务简单、最佳基线接近、可解释文本并非唯一真实原因，现实数据误报率未充分确立。已核查方法、主实验与局限；尚未复跑代码，建议优先作为审计研究而非用户画像工具。
