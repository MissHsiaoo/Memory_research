# 2. TreeFlex：让 agent 自主导航搜索树

- 论文：[arXiv:2610.20334](https://arxiv.org/abs/2610.20334) · [官方 PDF](https://arxiv.org/pdf/2610.20334) · 本地 PDF：`2610.20334.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Dongzhuo Li、Fangzhou Cheng 等；Meta AI。**机构优先级 P1**。
- 标签：agent memory；search-tree context；RL agent。证据范围：全文 32 页。

1. **做了什么（论文证据）**：把 agent 轨迹保存为带摘要的搜索树节点，让同一策略选择回溯位置，而非把所有失败尝试塞进一条线性上下文。
2. **怎么做/实验（论文证据）**：Reflection 角色查看节点摘要并选择续跑节点与指令，Execution 角色由 harness 恢复路径再用工具执行；用 GRPO 训练 4B 策略，与 ReAct/FoldAgent 在深度研究及 SWE-bench Verified 等任务比较。
3. **结论（论文证据）**：论文报告深度研究得分 48.8，对比 ReAct 41.5、FoldAgent 42.8；SWE-bench Verified 解题率 54.9%，对照 43.3%/45.2%。摘要树能减轻过期分支干扰，但收益也包含训练和搜索预算影响。
4. **未来影响（我的推断）**：搜索树可以成为长任务的可检查情节记忆；也能与跨会话摘要或可复用技能图衔接。
5. **Critical thinking**：树摘要是否遗漏后来关键证据？应在同等 token/工具调用/训练成本下与线性轨迹、外部检索比较，并测试节点污染、工具结果变更及跨会话重用。
6. **可信度 4/5**：优点是明确的机制、强任务基准与多个对照；局限是搜索结构与训练方法联动，独立贡献及更长生命周期中的存储成本仍需拆解。
