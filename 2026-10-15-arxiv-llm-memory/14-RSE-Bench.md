# 14. RSE-Bench：普通噪声如何伤害技能自进化

- 论文：[arXiv:2610.19910](https://arxiv.org/abs/2610.19910) · [官方 PDF](https://arxiv.org/pdf/2610.19910) · 本地 PDF：`2610.19910.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Tao Yu、Zhongtian Luo 等；JD Future Academy、CASIA、UCAS、Tsinghua University 等。**机构优先级 P2**。
- 标签：self-evolving agent memory；skill learning；robustness benchmark。证据范围：全文 35 页。

1. **做了什么（论文证据）**：提出 RSE-Bench，测 agent 在“写入技能”期间遇到非对抗噪声时的鲁棒性，而非只在技能冻结后扰动输入。
2. **怎么做/实验（论文证据）**：四领域、六基准，对指令、环境证据、执行记录和结果—记录配对施加受控扰动；评测三种技能进化方法与两类底座。
3. **结论（论文证据）**：带噪学习时，方法仅保留无噪增益的约 25.5–42.1%。这说明错误经验被固化是关键失败模式，不证明所有部署都会出现同一比例。
4. **未来影响（我的推断）**：技能写入需要来源可靠性、反事实回放与撤销机制；同样适用于个人偏好记忆的错误纠正。
5. **Critical thinking**：噪声强度和真实环境错误分布是否吻合？建议按写入时间/噪声类型报告学习曲线，加入置信度筛选和延迟确认基线。
6. **可信度 4/5**：因素控制和多方法交叉评估有价值；模拟扰动与真实世界日志污染的距离仍需检验。
