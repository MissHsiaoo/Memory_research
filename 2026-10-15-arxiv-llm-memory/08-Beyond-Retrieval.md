# 8. Beyond Retrieval：从证据读取到事件聚合

- 论文：[arXiv:2610.19474](https://arxiv.org/abs/2610.19474) · [官方 PDF](https://arxiv.org/pdf/2610.19474) · 本地 PDF：`2610.19474.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Zerui Yang、Quan Xue 等；Huawei Technologies。**机构优先级 P2（强产业实验室）**。
- 标签：agent memory；event aggregation；source evidence。证据范围：全文 27 页。

1. **做了什么（论文证据）**：指出 agent 历史问题常需数事件/聚合，单纯召回相似文本不足；提出原始轨迹可追溯读取的 TM 和事件台账 TallyMem。
2. **怎么做/实验（论文证据）**：保留源轨迹并在问答时构造可定位证据视图；把事件规范转成可执行聚合。评估 GitHub 轨迹 MINTEval、AMA-Bench，并用独立解析事件的受控探针隔离计数能力。
3. **结论（论文证据）**：776 问/99 个留出仓库上 Qwen3-32B exact match 35.2→49.0%；独立事件探针 82.8→93.8%；全 AMA-Bench 增幅仅 1.3 个百分点，表明收益依任务而异。
4. **未来影响（我的推断）**：长期记忆需要可审计的原始证据与可重复计算的派生事实，适用于“做过几次/何时发生”类问题。
5. **Critical thinking**：事件规格由模型生成会带解析偏差；台账难表达所有谓词。应发布错误分解，测跨域事件定义、增量更新和冲突日志，并给出存储/构建成本。
6. **可信度 4/5**：多读者、留出仓库与独立探针增强因果解释；论文也明确任务范围、单标注者误差分析和全基准增益较小的局限。
