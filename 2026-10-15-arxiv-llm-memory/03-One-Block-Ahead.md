# 3. One Block Ahead：扩散语言模型并行解码块

- 论文：[arXiv:2610.19510](https://arxiv.org/abs/2610.19510) · [官方 PDF](https://arxiv.org/pdf/2610.19510) · 本地 PDF：`2610.19510.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Yangyi Shen、Pin-Jui Ku 等；斯坦福大学、NVIDIA。**机构优先级 P1**。
- 标签：diffusion LLM；parallel sampling；inference。证据范围：全文 25 页。

1. **做了什么（论文证据）**：提出无训练的 One Block Ahead（OBA），使相邻的扩散解码块并发推进。
2. **怎么做/实验（论文证据）**：对均匀状态的 block diffusion 模型，提前计算下一块，同时传递 token、自条件信号及降噪时间等 sampler state；推导双块前向成本的盈亏条件，在 DiffusionGemma、10 个基准上测速度和准确性。
3. **结论（论文证据）**：平均每次前向产出 token 数增 42.3%，单请求降噪吞吐增 16.3%，伴有小幅准确性损失。论文明确限于 batch size 1、单一 GPU 类型和一个符合设定的模型。
4. **未来影响（我的推断）**：可与扩散模型的长上下文或检索机制组合，但不直接解决 agent memory。
5. **Critical thinking**：关键假设是下一块未完成时能安全继承足够的采样状态。需在多请求吞吐、不同硬件、非均匀状态/掩码扩散架构上复测，并绘制速度—准确率 Pareto 曲线。
6. **可信度 4/5**：有推导、实现和多基准；但模型/硬件/批大小范围窄，外推到通用 dLLM 不成立。**弱相关但具启发性**：启发点是将隐式采样状态显式当作跨块记忆。
