# 22. Evaluating Compressed Memory：依赖不等于有用

- 论文：[arXiv:2610.19373](https://arxiv.org/abs/2610.19373) · [官方 PDF](https://arxiv.org/pdf/2610.19373) · 本地 PDF：`2610.19373.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Minsu Oh、Seunghui Jwa 等；Jeju National University、Soongsil University。**机构优先级 P3（黑马/启发性补充）**。
- 标签：compressed memory；causal evaluation；negative result。证据范围：全文 35 页。

1. **做了什么（论文证据）**：反驳“把记忆向量置零后性能下降，就证明记忆内容有用”的常见评估推论。
2. **怎么做/实验（论文证据）**：把零化测试与分别训练的无记忆/固定输入替代模型对比，覆盖九种系统、故事状态预测和 TriviaQA 等，并分析内容关联与答案指标。
3. **结论（论文证据）**：一些模型确实依赖记忆输入，却不如训练好的无记忆替代；xRAG 输入无关文档时 TriviaQA F1 可由 19.38 升到 24.78，相关文档达 29.88，说明 F1 增益未必都是内容信息收益。
4. **未来影响（我的推断）**：latent memory 论文应至少同时报告依赖性、相对无记忆效用、内容相关性，而非只做零化消融。
5. **Critical thinking**：比较模型的训练机会与成本可能影响结论；需在更多架构、等预算和多随机种子下复测，并使用事实定位、人类审核等指标区分答对与表面重叠。
6. **可信度 4/5**：多系统与训练替代对照揭示实质性的评估盲点；作者承认无法证明全架构最优、未完全匹配预训练/推理成本。纳入原因是方法论洞见突出，非机构优先级。
