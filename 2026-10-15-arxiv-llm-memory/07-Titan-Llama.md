# 7. Titan-Llama：在预训练 LLM 上加神经记忆

- 论文：[arXiv:2610.19210](https://arxiv.org/abs/2610.19210) · [官方 PDF](https://arxiv.org/pdf/2610.19210) · 本地 PDF：`2610.19210.pdf`
- 公告：2026-10-15；初次提交：2026-10-13。
- 作者/机构：首页核验 Sarah Pan（MIT）、Ali Behrouz（Cornell）。**机构优先级 P2**。
- 标签：latent memory；test-time neural memory；long-context。证据范围：全文 15 页。

1. **做了什么（论文证据）**：提出无需从头预训练的 Titan-Llama，为注意力模型补充固定大小的外部神经记忆模块。
2. **怎么做/实验（论文证据）**：以块状注意力保存近期信息的精确访问，用循环更新的神经记忆压缩远期历史；后训练改造 Llama 3.2-1B，并测长文本问答及预填充/解码效率。
3. **结论（论文证据）**：论文报告 QuALITY 23.87→40.51%，LongHealth 14.50→40.75%；特定配置下预填充快逾 20%，解码快 37%，解码内存低 24%。
4. **未来影响（我的推断）**：让既有 LLM 获得部分参数化长程记忆，可能降低改造门槛；但仍需与外部可编辑记忆协同。
5. **Critical thinking**：压缩的远期记忆能否精确恢复罕见事实、支持删除和逆转？应测试多模型尺度、长度外推、被遗忘信息的位置偏差，并控制硬件/缓存设置。
6. **可信度 3/5**：有模型构造和效率/质量双重测量；主实验模型仅 1B，面向更大模型及多用户场景的泛化证据有限。
