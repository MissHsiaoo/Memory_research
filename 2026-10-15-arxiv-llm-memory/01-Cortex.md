# 1. Cortex：将上下文收益固化为参数记忆

- 论文：[arXiv:2610.20399](https://arxiv.org/abs/2610.20399) · [官方 PDF](https://arxiv.org/pdf/2610.20399) · 本地 PDF：`2610.20399.pdf`
- 官方公告批次：2026-10-15；初次提交：2026-10-14。两者不是同一日期。
- 作者/机构：首页核验 Jintian Zhang、Feng He 等；浙江大学、ByteDance Seed、清华大学。**机构优先级 P1（指定重点机构）**。
- 标签：latent/parametric memory；context consolidation；continual editing。证据范围：全文 99 页，含方法、实验及附录。

1. **做了什么（论文证据）**：把上下文撤去后仍能保留其收益、同时不损伤非目标能力，形式化为 memory consolidation，并提出 Cortex。
2. **怎么做/实验（论文证据）**：先生成可能用到当前上下文的前瞻问题，再把有上下文的回答蒸馏为可合并的低秩或前馈网络结构更新；五类任务、单次/批量/连续更新，覆盖 4B–120B、稠密/MoE及多模态模型，并同时测收益保留与副作用。
3. **结论（论文证据）**：多数设置落在 consolidation–retention 的经验 Pareto 前沿；14B 模型连续 50 次事实编辑后，结构版保留上下文增益的 88.9%，非目标原始性能保留 99.8%。这是作者的测量结果，不等于任意开放环境的永久记忆。
4. **未来影响（我的推断）**：可能把外部短期上下文转为低成本内部长期记忆；尤其值得与个性化记忆的可撤销、用户隔离设计结合。
5. **Critical thinking**：核心假设是生成的前瞻问题覆盖未来真实使用分布。需测试长期分布漂移、互相矛盾的用户事实、删除权和隐私泄露；以相同更新预算对比 RAG、LoRA 与直接重训，并报告连续千次更新的冲突率。
6. **可信度 4/5**：优点是跨模型、跨任务且显式衡量保留与干扰，PDF 给出具体协议；局限是前瞻问题由模型生成，开放式真实用户历史和长期遗忘/删除并未由这些指标完全证明。机构等级不参与此分数。
