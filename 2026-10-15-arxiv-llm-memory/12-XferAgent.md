# 12. XferAgent：跨 agent 经验迁移

- 论文：[arXiv:2610.19581](https://arxiv.org/abs/2610.19581) · [官方 PDF](https://arxiv.org/pdf/2610.19581) · 本地 PDF：`2610.19581.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Weihao Li、Jun Bai 等；Northwestern University、McGill University、Mila、Ohio University。**机构优先级 P2**。
- 标签：agent memory；experience transfer；self-improvement。证据范围：全文 14 页。

1. **做了什么（论文证据）**：让执行历史不同的 agent 共享可复用经验，而不简单合并原始轨迹。
2. **怎么做/实验（论文证据）**：维护本地与共享经验图；贡献前去掉任务专属、执行敏感内容，兼容时合并；新任务按目标 agent 历史选择共享经验。跨多任务领域和代表性记忆基线比较。
3. **结论（论文证据）**：作者报告跨域任务性能与复用效率改善；此处不写未独立复核的单一数字，结论限定在其评测协议内。
4. **未来影响（我的推断）**：组织内多 agent 可以积累可迁移操作知识，但需把共享粒度和隐私边界一起设计。
5. **Critical thinking**：删去敏感字段并不等于隐私保证；图合并也可能传播错误。应测恶意经验注入、跨任务负迁移、隐私重识别和随代理数量增长的维护成本。
6. **可信度 3/5**：论文给出机制及跨域比较；作者明言没有正式隐私保证、仅文本经验，未隔绝所有任务泄漏风险。
