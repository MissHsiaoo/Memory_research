# 15. MemCode：离散语义码的长期 agent 记忆

- 论文：[arXiv:2610.19472](https://arxiv.org/abs/2610.19472) · [官方 PDF](https://arxiv.org/pdf/2610.19472) · 本地 PDF：`2610.19472.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Xin Li、Liang Hu 等；同济大学、WorldMind。**机构优先级 P2**。
- 标签：agent long-term memory；semantic quantization；associative retrieval。证据范围：全文 27 页。

1. **做了什么（论文证据）**：尝试修正长时对话记忆的写入单元不稳定、词面相远的相关证据漏检问题。
2. **怎么做/实验（论文证据）**：先写成自包含原子记忆单元（AMU），再映射到可学习离散 codebook，以语义码共现拓扑补充向量搜索；在线写入与异步离线巩固分离，评测 LongMemEval-S/LoCoMo、两种底座。
3. **结论（论文证据）**：作者报告多设置最佳准确率，单对话构建约 40–130 秒，较 LightMem 约快 3–21 倍；但开放式问题上全上下文方法仍有竞争力。
4. **未来影响（我的推断）**：离散码可能提供可检查、可聚合的中间索引；若与源文本绑定，可支持记忆调试。
5. **Critical thinking**：AMU 改写会遗漏语用和隐含动机，码本也会随用户行为漂移。应测在线反复更新、码本碰撞、删除与错写恢复。
6. **可信度 3/5**：有明确检索机制和两个常用基准；作者明确只验证偏检索的对话记忆，未验证完整规划/工具 agent，也未测试图结构长期维护。
