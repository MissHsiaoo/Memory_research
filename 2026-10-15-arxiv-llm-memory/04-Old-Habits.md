# 4. New Model, Old Habits：换模型时的行为记忆迁移

- 论文：[arXiv:2610.19712](https://arxiv.org/abs/2610.19712) · [官方 PDF](https://arxiv.org/pdf/2610.19712) · 本地 PDF：`2610.19712.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Youngbin Choi、Sehyun Hwang 等；POSTECH、Meta。**机构优先级 P1**。
- 标签：multi-session agent；behavior transfer；history summarization。证据范围：全文 27 页。

1. **做了什么（论文证据）**：研究跨会话 agent 换底座模型时，历史记录如何把旧模型的推理/行动习惯传给新模型，并提出 DASH 摘要。
2. **怎么做/实验（论文证据）**：在控制模型对和会话边界的多轮任务中比较原始历史、普通摘要和方向/作者感知摘要；重复强弱模型互换，覆盖网页购物、旅行规划。
3. **结论（论文证据）**：原始历史最易产生行为迁移；摘要显著降低弱模型习惯污染强模型，DASH 旨在保留强到弱的有益迁移。作者承认尚未联合优化换模型时机。
4. **未来影响（我的推断）**：跨模型共享 agent memory 应区分“用户事实”和“生成者行为轨迹”，而不是无差别压缩。
5. **Critical thinking**：摘要器是否会偏向所谓强模型、抹掉用户偏好或关键失败证据？应盲测更大模型池、动态换模、成本匹配，以及独立的人类偏好/任务成功率。
6. **可信度 4/5**：控制变量和重复交换实验较扎实；但只测固定模型对、预定边界及两类任务，真实运营迁移仍待验证。
