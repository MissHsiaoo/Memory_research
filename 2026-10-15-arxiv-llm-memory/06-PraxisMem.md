# 6. PraxisMemBench：个人与流程记忆的耦合

- 论文：[arXiv:2610.20022](https://arxiv.org/abs/2610.20022) · [官方 PDF](https://arxiv.org/pdf/2610.20022) · 本地 PDF：`2610.20022.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Maosheng Qin、Qi Zhang 等；浙江大学、蚂蚁集团。**机构优先级 P2（高水平高校/实验室）**。
- 标签：personalized memory；procedural memory；persistent assistant。证据范围：全文 51 页。

1. **做了什么（论文证据）**：提出 PraxisMemBench 与 PraxisMem，聚焦“用户是谁”的个人记忆与“如何做”的流程记忆之间的依赖。
2. **怎么做/实验（论文证据）**：构造生活/工作跨会话轨迹，使后续任务同时依赖偏好、身份事实和流程；比较分开存储、原生代理记忆及联合维护，并做依赖类型分析。
3. **结论（论文证据）**：交叉依赖时任务完成率由单类任务约 84.6% 降至 77.9%；其方法会话成功率 40.78%，对比 Claude Code 原生记忆 20.60%（论文特定 harness）。
4. **未来影响（我的推断）**：个人助理记忆的数据模型应显式记录“此流程适用于哪些人/条件”，而非两个独立向量库。
5. **Critical thinking**：基准里的用户轨迹与评分规则能否代表真实偏好变化？应增加用户纠错、冲突偏好、撤回同意和跨域任务，尤其做无记忆/单类记忆/联合记忆的成本匹配消融。
6. **可信度 4/5**：明确的双记忆依赖设计与对照有说服力；但方法增益基于作者定义的任务和 harness，不宜直接外推到真实长期部署。
