# 10. EGCForest：企业群聊的多视图记忆森林

- 论文：[arXiv:2610.19836](https://arxiv.org/abs/2610.19836) · [官方 PDF](https://arxiv.org/pdf/2610.19836) · 本地 PDF：`2610.19836.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Lingxi Cui、Jinhao Ruan 等；浙江大学、杭州高新区相关研究所、小红书。**机构优先级 P2**。
- 标签：enterprise agent memory；multi-view structure；retrieval。证据范围：全文 13 页。

1. **做了什么（论文证据）**：针对群聊交叉线程、发言者身份和产物引用，提出保留不可变消息日志的结构化记忆。
2. **怎么做/实验（论文证据）**：把同一日志组织成 Channel、Actor、Artifact 三类森林并建立跨视图链接；在三个企业群聊问答基准与 RAG/摘要记忆系统比较。
3. **结论（论文证据）**：论文报告最高比 MemOS 提升 20.85 个百分点。此结果证明特定问答数据上的检索收益，尚非对企业 agent 全流程收益的证明。
4. **未来影响（我的推断）**：多视图与源日志并存，可减少摘要丢失组织关系，并支持可溯源权限检查。
5. **Critical thinking**：构建成本和持续更新如何随频道数增长？作者局限也指出仅测问答、较大/频繁变化工作区需要增量维护。后续应测权限变更、敏感对话隔离和任务协调。
6. **可信度 3/5**：有三个数据集和清晰的数据结构；企业真实部署的安全、在线维护和下游任务尚未验证。
