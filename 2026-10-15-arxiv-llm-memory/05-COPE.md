# 5. COPE：行动与预测共同进化

- 论文：[arXiv:2610.20597](https://arxiv.org/abs/2610.20597) · [官方 PDF](https://arxiv.org/pdf/2610.20597) · 本地 PDF：`2610.20597.pdf`
- 公告：2026-10-15；初次提交：2026-10-14。
- 作者/机构：首页核验 Haofei Yu、Yixing Chen 等；UIUC、UC San Diego、Meta AI。**机构优先级 P1**。
- 标签：self-evolving agent；trajectory learning；forecasting。证据范围：全文 31 页。

1. **做了什么（论文证据）**：提出 COPE，使语言 agent 用成功轨迹的中间步骤预测未来多步行动，改善长程强化学习的样本效率。
2. **怎么做/实验（论文证据）**：对 on-policy 成功轨迹中的每个历史前缀增加未来行动序列监督，与只用终局奖赏或短期观测目标的训练比较；测五个基准与样本效率，推理时不增加额外预测调用。
3. **结论（论文证据）**：ScienceWorld 中相对 ECHO/GRPO 最高约 1.9×/2.0× 样本效率；这是训练经验复用而非明确的持久记忆存储。
4. **未来影响（我的推断）**：可作为 agent 记忆写入策略的训练信号：成功轨迹不只存文本，还可训练对未来动作的可迁移预测。
5. **Critical thinking**：成功轨迹筛选可能忽视失败中的重要知识，也可能把环境偶然性当成规律。需比较相同成功样本和计算预算、未知环境转移及失败轨迹的增益。
6. **可信度 3/5**：任务覆盖较广、训练/推理开销区分清楚；对长期记忆系统的联系主要是本文推断，不能将样本效率直接读成跨会话记忆改进。**弱相关但具启发性**。
