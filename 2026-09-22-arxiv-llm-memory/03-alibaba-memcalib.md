# MemCalib: Benchmarking and Optimizing Memory Use in LLM Agents

- arXiv：[24259](https://arxiv.org/abs/2609.24259)；[官方 PDF](https://arxiv.org/pdf/2609.24259)

- 机构：Alibaba Qwen Applications Business Group；中国科学技术大学；复旦大学（论文 PDF 首页核验）

## 1. 做了什么

MemCalib 不问 agent 能否检索到记忆，而问它是否应该使用、应以多大强度使用。这把“过度个性化”和“忽视偏好”纳入统一决策问题；与只追求记忆命中率的论文相比，新颖点是按记忆原子的实际作用分配训练反馈。

## 2. 怎么做，实验怎么做的

作者构造约 1.5 万条跨健康、通用、编码场景样例，其中约 1500 条为测试；每条有多条记忆原子及理想使用等级。评价的 SCS 衡量使用校准，Exact 更严格。MemCalib-RL 通过有序双向反事实删去记忆原子估计贡献，再分配 token 级信用。采用 DeepSeek-V4-Pro 做记忆使用等级判定，150 条人工核查报告 96.7% 一致率、κ=0.872。表 2 中 Qwen3-8B 的 SCS/Exact 为 79.54/67.89，对比 GRPO 67.61/52.18；还测三模型、三随机种子及外部 RPEval。

## 3. Conclusion

在该评测与判分框架下，反事实信用分配显著改进“何时使用记忆”；这不是证明 agent 在真实用户场景总会尊重边界。人评覆盖小样本，LLM judge 可能与训练目标形成闭环偏好。

## 4. Future impact

“记忆使用强度”比“是否检索”更贴近产品体验，可成为个性化 agent 的训练中间指标。我的推断是它也适用于动态权限：用户临时拒绝某偏好时，系统应自动降权而非仅删除上下文。

## 5. Critical thinking

关键可疑点是删去一条记忆的输出差异能否当成其真正因果贡献；多记忆互相替代时，单原子边际效应会误导归因。建议做成组反事实、冲突记忆、敏感属性泄露与偏好撤销实验，另用独立 judge 和真实用户盲评重新校准 SCS。健康域涉及高风险，不应把自动评分改进误读为医疗可靠性提升。

## 6. 可信度判断、优点与局限

4/5：方法、训练消融、人工一致性和外部测试已核查。优点是把记忆调用转为可测、可优化的校准问题；局限是合成 rubric 与同家族 judge 依赖、真实用户效度不明。机构优先级和证据分数分开。
