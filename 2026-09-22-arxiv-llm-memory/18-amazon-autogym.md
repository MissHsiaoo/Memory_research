# AutoGym: Blueprint-First Generation of Verifiable Agent Gyms

- arXiv：[22592](https://arxiv.org/abs/2609.22592)；[官方 PDF](https://arxiv.org/pdf/2609.22592)
- arXiv 初次提交：2026-09-18（v1）；正式公告归属：2026-09-22 新稿，二者不可混同。
- 作者：Aarati Andrea Noronha , Kavya Ravikumar , Carly Xiaoyu Lin（arXiv 官方列表）
- 机构：Amazon AGI（论文 PDF 首页核验）
- 机构优先级：A｜顶级产业研究
- 研究标签：agent 自进化；可验证训练环境；工具学习；弱相关但具启发性
- 证据说明：以下数值均为论文自身报告；“我的推断/建议”并非论文实证。

## 1. 做了什么

AutoGym 不是直接研究 LLM memory，而是自动构建可验证的 agent 练习环境。它之所以入选，是因为 self-evolving memory 要有可靠反馈；若练习任务和验证器本身不可信，所谓“积累经验”可能只是反复学习漏洞。

## 2. 怎么做，实验怎么做的

流程先写环境蓝图及任务规格，再生成实现与可执行验证器，并迭代修复；比较生成环境与人工环境的难度和真实感。作者构造约 300 个人工专家任务作参照，自动生成低难度约 297 个、中高难度约 280 个；在 Claude Opus 4.6 上，人工任务的高难比例 21.5%，AutoGym C2 为 39%；另报告界面真实感 78/100、环境真实感 86/100。还做一个 8B 模型约 500 步 GRPO 训练试验，不能据此证明大规模训练持续获益。

## 3. Conclusion

蓝图先行能稳定生成更有挑战的可检验任务，但“可验证”只表示在当前规则下可判分，不保证反馈与真实用户价值一致。弱相关纳入是看重其对自进化评测的底层启发，不把它称作新记忆算法。

## 4. Future impact

未来 agent memory 研究可用自动 gym 产生错误经验、过时工具和冲突规则，用于测试记忆更新与遗忘；但验证器需独立审计，防止 agent 记住评分漏洞。这是我建议的延伸。

## 5. Critical thinking

自动生成的任务/验证器同源，可能共享盲点；高难比例也可能反映模糊任务而非深层能力。应做人类盲评、跨模型迁移、真实仓库/网页外部任务及环境漏洞攻击，并把构建与修复成本算进训练收益。单一 8B 的短 RL 测试不足以宣称通用训练有效。

## 6. 可信度判断、优点与局限

3/5：论文有大量任务生成与环境测试，优点是可验证基础设施明确；局限是评价器同源性、真实感主观量表、RL 训练证据有限。
