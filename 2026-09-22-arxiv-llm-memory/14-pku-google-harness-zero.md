# Harness-Zero: Harness Distillation via Agent-as-Harness

- arXiv：[24974](https://arxiv.org/abs/2609.24974)；[官方 PDF](https://arxiv.org/pdf/2609.24974)
- arXiv 初次提交：2026-09-21（v1）；正式公告归属：2026-09-22 新稿，二者不可混同。
- 作者：Haoran Ye , Yuxing Lu , Haonan Dong , Zhaochen Su , Guojie Song（arXiv 官方列表）
- 机构：北京大学；Google；香港科技大学（论文 PDF 首页核验）
- 机构优先级：A｜顶级产业与一流高校合作
- 研究标签：agent 能力内化；训练记忆；自改进；相关但非用户记忆
- 证据说明：以下数值均为论文自身报告；“我的推断/建议”并非论文实证。

## 1. 做了什么

Harness-Zero 探索把训练时外部 harness 对 agent 的审查/纠偏内化进模型参数，从而减少部署时昂贵的逐步指导。它不是跨会话私人记忆，但属于“执行经验与反馈如何变成 agent 内在能力”的相关方向。

## 2. 怎么做，实验怎么做的

训练阶段由 agent-as-harness 审核候选动作并生成更好轨迹，将这些轨迹蒸馏进 Qwen3.5-9B 的 LoRA 学生；部署时学生在固定 mini-SWE harness 下运行。实验跨 Spreadsheet、AppWorld、USPTO 等任务。论文表 2 基础学生平均 23.3，经目标 harness 41.7，蒸馏学生 44.3，约 +21.0 个百分点；分项 Spreadsheet 44 对目标 harness 31、AppWorld 58.9 对 26.8，但 USPTO 30 低于目标 harness 38。训练数据约 487+282+500 条轨迹；额外采集与审查成本要计入。

## 3. Conclusion

特定多任务设置下，外部审查的经验可以内化，带来无需在线 harness 的收益；效果高度任务依赖，专业任务 USPTO 不支持“蒸馏必优于目标”的笼统说法。

## 4. Future impact

可把昂贵的“记忆使用审计”放在离线训练，让轻量 agent 学会何时取证、何时拒绝。长期用户偏好需要可撤回、可更新，因此参数化内化不能完全替代外部记忆。这是我的推论。

## 5. Critical thinking

训练时审查每一步提高数据质量却消耗调用预算；应测完整成本摊销点及学生在工具变化后是否仍遵循旧套路。跨任务均值掩盖 USPTO 逆转，也应报告每项方差和训练样本敏感性。最有价值的压力测试是让审核器给出带偏差建议，观察学生是否把错误政策永久学进去。

## 6. 可信度判断、优点与局限

4/5：方法、样本数、跨任务分项已查；优点是训练/部署角色分离清晰，提升较大；局限是训练成本、部分任务回退和缺乏长期可撤回性。
