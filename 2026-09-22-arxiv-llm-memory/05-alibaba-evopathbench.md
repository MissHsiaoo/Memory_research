# Beyond Endpoint Performance: Process-Level Evaluation of Self-Evolving Agents

- arXiv：[24663](https://arxiv.org/abs/2609.24663)；[官方 PDF](https://arxiv.org/pdf/2609.24663)
- arXiv 初次提交：2026-09-21（v1）；正式公告归属：2026-09-22 新稿，二者不可混同。
- 作者：Hongqiang Lin , Chao Liu , Xiaofan Bai , Xuan Jin , Yuhong Li , Nenggan Zheng , Xipeng Cao（arXiv 官方列表）
- 机构：Alibaba Group；浙江大学（论文 PDF 首页核验）
- 机构优先级：A｜顶级产业研究
- 研究标签：self-evolving agent memory；过程评测；策略更新；技能；直接相关
- 证据说明：以下数值均为论文自身报告；“我的推断/建议”并非论文实证。

## 1. 做了什么

EvoPathBench 认为只看最终得分无法判断 agent 是否真的从经验中学习。它把自进化拆成迁移到新任务、保留旧能力、根据新证据修正规则三种可检验过程，是对“记忆/技能库越积越好”叙事的直接压力测试。

## 2. 怎么做，实验怎么做的

基准含 1800 条流、六类任务与两个市场域；固定基础模型和工具，在 K0 至 K5 阶段冻结 agent 产物，在留出样本上追踪能力变化。比较经验记忆、技能整理等 10 种配置，控制是否共享历史及更新机制。论文主表显示 SkillBoost 等策略在部分迁移指标更好，但保留与规则适应不能同步保证；作者总结没有方法可靠完成规则适应。因使用历史金融数据，这只是模拟环境中的 agent 过程评测，不是金融策略建议。

## 3. Conclusion

终点分数高并不意味着持续学习稳健；显式检测“先学会、后遗忘”和“证据改变后仍坚持旧规则”可揭露当前 agent memory 的主要失败方式。论文给的是评测框架和经验观察，不是通用自进化解法。

## 4. Future impact

值得把其冻结时点和保留/迁移/适应三轴改造成未来记忆系统的标准回归测试。我的推断是研发流程应对每次记忆更新做旧任务回放，而不是只报告最新任务成功率。

## 5. Critical thinking

构造任务基于有限市场域，规则变化可能比真实用户偏好变化更形式化；“迁移”也可能被相近数据模板放大。建议换成客服/编码/学术研究流，隐藏更新时间和变化方向，加入恶意经验、删除请求、长期成本。若同一基础模型生成流与评价流，要特别核对内容重合和 judge 泄漏。

## 6. 可信度判断、优点与局限

4/5：已看构造、指标、阶段冻结和多配置实验。优点是过程评估比端点指标有诊断力；局限是市场模拟到一般 agent 外推有限，某些指标解读依赖其定义，尚缺真实长期部署验证。
