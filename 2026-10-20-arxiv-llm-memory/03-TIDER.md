# 3. TIDER：强化学习定位时间窗口的双通道长期记忆检索

- **arXiv**：[2610.23598](https://arxiv.org/abs/2610.23598)；[官方 PDF](2610.23598.pdf)
- **提交日期**：2026-10-16（v1）。
- **作者/机构**：Dabin Sheng 等。PDF 首页核验：清华大学（教育部普适计算重点实验室），Qiyuan Lab。
- **机构优先级**：P1（清华研究团队）。**研究标签**：agent memory；时间检索；RL；LifeBench、LoCoMo。
- **证据范围**：完整 PDF，45 页；文件可解析。

## 1) 做了什么

提出 TIDER，指出语义相似检索会被“时间不对但主题相似”的旧记忆干扰；在检索阶段先预测证据可能所在的时间区间，再与语义检索结果融合。

## 2) 怎么做、实验如何设计

一个 1.7B 时间区间定位器通过 RL 学习离散窗口选择；复合 reward 把答案正确性与证据覆盖等稀疏信号转为检索决策反馈。定位的时间窗口形成 temporal channel，再与 semantic channel 合并，按距窗口时间接近度重排。作者在 LifeBench 和 LoCoMo 做主实验、按窗口数分层、模块/定位器替换和超参消融，亦讨论了合成个人史、上游 memory item 依赖、语言范围等限制。

## 3) 结论

论文报告 LifeBench 61.52%（相对基线 +8.82 个百分点）、LoCoMo 78.96%（+3.66 个百分点），支持时间约束应直接进入候选检索而非只在组织或生成阶段处理。

## 4) 未来影响

长期个人记忆中“何时发生”与“发生了什么”同等重要。时序窗口作为独立检索通道可以与事实图、事件摘要和用户画像共存，而非替代语义检索。

## 5) Critical thinking

- **关键假设**：问题可以从上下文中被定位到较窄时间窗口；训练奖励足以教会定位器估算窗口而不学习数据集时间捷径。
- **差别**：把 temporal cue 加到检索候选选择阶段，并以双通道融合；不是仅在整理记忆或回答时附上日期。
- **风险**：用户时间表达模糊/相对、记忆时间戳错误、事件跨多个窗口时，定位器可能把正确事实排除；长历史分布与 benchmark 语料差异也会影响迁移。
- **后续建议**：在跨语言、无日期显式提示、时区/时间修正、重复事件和矛盾记忆上评测；报告窗口召回、额外检索成本以及定位失败带来的最坏情形。

## 6) 可信度判断

**4/5。** 依据：全文提供多个 benchmark、轻量定位器、分层分析、消融和显式 limitations。优点是任务诊断与设计对应；局限是 benchmark 的个人历史为合成构造，且总体效果仍取决于上游存储的记忆质量，真实个人语料效度待验证。
