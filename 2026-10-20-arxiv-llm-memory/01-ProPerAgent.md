# 1. ProPerAgent：记忆驱动的主动式个性化帮助

- **arXiv**：[2610.22671](https://arxiv.org/abs/2610.22671)；[官方 PDF](2610.22671.pdf)
- **提交日期**：2026-10-15（arXiv v1）；本次官方 New submissions 批次为 2026-10-19（美国东部），对应北京时间 2026-10-20。
- **作者/机构**：Shenglai Zeng 等。PDF 首页核验：Michigan State University、Meta Reality Labs、Meta Superintelligence Labs、Meta Recommendation Systems、University of Washington。
- **机构优先级**：P1（Meta 研究团队与一流高校联合）。**研究标签**：主动式个性化助手；个人长期记忆；benchmark；检索/中断门控。
- **证据范围**：完整 PDF 与 arXiv HTML；不是仅摘要判断。

## 1) 做了什么

提出 ProPerMem benchmark，把“从长期个人记忆找出可干预的事实”与“判断恰当打断时间、生成有根据的内容、其余时间保持沉默”合并评测；并提出 ProPerAgent 作为图组织记忆、检索和中断门控系统。

## 2) 怎么做、实验如何设计

ProPerMem 配对第一人称视频与约一年、平均约 618K tokens 的用户历史；每个样例有人核验的触发窗口及目标提醒。主指标要求恰好一次在窗口内发出内容正确的提醒；另有 150 个不应响应的负样例。数据共 1,804 对（904/100/800 train/dev/test），使用 Ego4D 视频及受控合成的生活史。作者用 oracle evidence × timing 给定/自选的因子实验区分检索内容与时机两种瓶颈。ProPerAgent 以图式 episodic/semantic memory 找候选，再过滤“准确但不值得打断”的记忆；另用轻量 RL 抑制过早/重复触发。

## 3) 结论

论文报告：GPT-5.3-Chat 在 oracle 证据且时机给定时 strict accuracy 为 96%，让模型自己选时间降至 38%，再将 oracle 换成检索降至约 15%。ProPerAgent 无额外训练时在 Qwen3.8-27B/GPT-5.3-Chat 上分别达到 37.5%/38%，RL 后训练达到 42.4%。这些是作者在该受控 benchmark 上的结果，不代表自然场景的部署成功率。

## 4) 未来影响

把 memory agent 的目标从“检索到相关记忆”推进到“恰在有帮助的时刻，用准确证据发出一次必要干预”。benchmark 可促使未来系统同时报告内容精确度、触发时机、重复打扰及静默能力。

## 5) Critical thinking

- **关键假设**：合成的长历史、触发窗口与 LLM judge 能代表用户真正需要提醒的时机和内容；时间戳/场景理解正确时，系统能够可靠判断打断价值。
- **与既有工作的差别**：相比提供短用户画像或显式目标的 proactive benchmark，本作要求从 618K token 长史中检索依据，并联合打分内容与时机。
- **可能失败情形**：真实用户目标变化、模糊提醒效用、多提醒冲突、摄像头缺帧、隐私约束和偏好纠错都可能破坏受控设定；误报会造成用户注意力成本，漏报则未必有可见的即时损失。
- **后续实验建议**：预注册人类评审与可接受干预区间；跨用户/文化群体划分；报告每小时误打扰、长期信任及撤回/更正记忆后的表现；分别测试真实而非合成的用户记忆，并审计训练/评测泄漏。

## 6) 可信度判断

**4/5。** 依据：完整论文呈现了数据规模、划分、负例、严格指标、oracle 因子分析、多个模型和 RL 消融。优点是把“何时/说什么/是否沉默”拆开分析，证据链清楚；局限是数据受控合成、关键评判部分依赖 LLM judge，作者说明数据与代码待发表后释放，独立复现与真实用户效度尚未建立。此分数评估证据，不等同机构排名。
