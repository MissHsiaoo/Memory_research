# 2. MFM：面向长期具身 agent 的多模态文件系统记忆

- **arXiv**：[2610.22686](https://arxiv.org/abs/2610.22686)；[官方 PDF](2610.22686.pdf)
- **提交日期**：2026-10-15（v1）。
- **作者/机构**：Chloe Su 等。PDF 首页核验：Harvard/Kempner Institute、NYU、UIUC、Northeastern University、MIT。
- **机构优先级**：P1（一流研究型高校/实验室联合）。**研究标签**：具身 agent memory；多模态/空间记忆；经验巩固；技能复用。
- **证据范围**：完整 PDF，40 页；文件可解析。

## 1) 做了什么

提出 MFM（Multimodal Filesystem Memory），把 episodic、spatial、semantic、procedural 和 working memory 放在一个可搜索文件系统内，并在可复用知识上保留指回原始多模态观测的证据指针，支持长期具身任务。

## 2) 怎么做、实验如何设计

每一步把观察/动作/结果与交互 ID 持久记录；需要历史时按当前目标与场景形成 cue query，检索事件索引，再查看相应原始视觉记录；巩固过程把事件更新为事实、关系、计划或可执行程序，同时保留 episode archive 和索引。实验涵盖 Minecraft 长程任务与 CUABench-KiCad computer-use，三个基础模型，比较无记忆及多种 memory baseline，并给出跨任务技能复用案例和消融。作者报告在 Minecraft Ender Dragon 达到 24 个里程碑中的 16 个（最佳 baseline 平均 12.7），CUABench-KiCad 平均 reward 0.440（最佳 baseline 0.400，无持久记忆 0.267）。

## 3) 结论

论文结果支持显式保留多模态经历指针、空间信息及可修订程序，能帮助这些长程模拟/计算机操作任务；纯摘要可能删掉后来才重要的视觉/空间细节。

## 4) 未来影响

可将“压缩历史”和“保留可回溯证据”结合：记忆不仅是摘要文本，而是结构化索引加可检查原始事件。对 GUI、机器人和科研 agent，可把成功轨迹转为有来源的程序，再在新状态下复核适用条件。

## 5) Critical thinking

- **关键假设**：任务环境提供可用 episode boundary/巩固触发；代理写出的知识和技能可在之后检索并迁移。
- **差别**：相较只存摘要、技能库或按相似度召回，MFM 重点是 filesystem 统一组织、空间索引和知识到原始多模态证据的链接。
- **风险**：文件系统和多类记忆会带来维护、存储、检索延迟与错误巩固成本；技能在环境状态稍变时可能失效；基准任务可能被长预算/专门工具结构所偏置。
- **后续建议**：测量长期存储/索引成本；在环境变化、错误观测、相互矛盾记忆中做压力测试；报告技能迁移成功率与错误程序造成的损害；让基线获得相同预算和原始观测访问权。

## 6) 可信度判断

**4/5。** 依据：全文包含清晰算法、实现细节、跨模型长程任务、消融与案例。优点是结果覆盖不同任务，且以例子展示 memory 如何改变决策；局限是重点环境有限、部分极长 Minecraft 结果来自有限运行，实际开放世界的分布漂移与 memory 运维成本仍未证明。
