# 07 — CommunityKV: Efficient Long-Context Decoding via Graph Partitioning

- arXiv：[2610.00418](https://arxiv.org/abs/2610.00418)；[官方 PDF](https://arxiv.org/pdf/2610.00418)；[本地 PDF](./2610.00418.pdf)
- v1 提交：2026-09-30；正式公告：2026-10-02（北京时间）
- 作者/机构（PDF 首页核验）：Joe McKenna 等；Amazon AGI
- 机构优先级：**S，头部企业研究团队**；研究标签：`long context` `KV memory` `sparse retrieval`
- 证据范围：核读 PDF 方法、实验；性能数据来自作者报告。

## 1. 做了什么

把长上下文 KV 选择改写为图社区检索，降低训练外稀疏注意力的语义粗糙与流式更新成本。

## 2. 怎么做、实验如何设计

从预填充阶段已算出的 QK 分数建立 token 图，依据直接注意和共同被注意关系分区；新 token 以常数时间分配到社区，无需全局重新聚类。PDF 在 Qwen3/Llama-3.1 的三个长上下文基准测试准确率、端到端吞吐和 GPU 内存，控制社区大小、每头与查询组聚合；作者报告相对密集注意力最高 1.25× 吞吐，组聚合最高 1.71× 且准确率相近。

## 3. Conclusion

KV cache 的读出可以利用图结构和局部增量更新，而非每轮重新做昂贵全局检索。

## 4. Future impact

对高频长期记忆读取有启发：经验条目可以按依赖社区组织，再增量并入新信息。

## 5. Critical thinking

**推断：** 预填充图可能随任务切换而过时；按社区取 token 可能错过跨社区稀疏证据。应测试多跳、频繁主题漂移、极长生成与不同硬件，报告建图峰值内存和端到端成本。

## 6. 可信度判断

**4/5。** 两模型家族、准确率/吞吐/内存兼顾；最高加速不代表所有设置都有该收益。
