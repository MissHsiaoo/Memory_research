# 06 Evo²：模型权重与代理 harness 协同进化

- 论文：[arXiv:2610.13025](https://arxiv.org/abs/2610.13025) · [官方 PDF](https://arxiv.org/pdf/2610.13025) · [本地 PDF](2610.13025.pdf)
- 日期：**2026-10-12 正式公告**；2026-10-09 提交。
- 作者：Chejian Xu、Shujian Zhang、Wenxuan Zhou、John Lambert、Beck Chen、Bo Li、Andrew Hard、Rajiv Mathews。机构：Google DeepMind、University of Illinois Urbana-Champaign（PDF 首页核验）。
- 机构优先级：A（Google DeepMind）；研究标签：self-evolving agents、harness optimization、agent memory transfer。

1. **做了什么｜论文证据：**提出 Evo²，使同一策略既提议 harness 修改又反思执行结果，权重更新与 harness 更新相互提供学习信号。
2. **怎么做、实验如何设计｜论文证据：**Proposer/Reflector 双角色共用策略；EvoTIDE 从编辑轨迹提取可训练片段、前缀续写恢复样本，再结合 SFT 与交错 GRPO。比较 3 个编码任务基准，并测试跨任务 harness 迁移与 LoCoMo、LongMemEval 记忆任务。
3. **结论｜论文证据：**摘要报告 Polyglot 82.1%、SWE-bench Verified 48.3%，相应最强基线为 62.6% 与 41.0%；还报告进化 harness 可迁移及记忆基准收益。数字仅代表文中设置。
4. **未来影响｜我的推断：**自进化对象由“模型或外部脚手架二选一”转向耦合系统，可能改变代理持续改进的实验设计。
5. **Critical thinking｜我的推断：**两条反馈回路会互相改变训练分布，使收益归因和过拟合检测更难。建议固定模型/固定 harness/交替更新三组等计算量对照，并使用真正未见的环境及失败回滚指标。
6. **可信度：4/5。**依据：核查了框架、训练过程和跨编码/记忆实验；优点是多任务与迁移测试，局限是自进化计算预算及测试污染/可复现性需更细审计。
