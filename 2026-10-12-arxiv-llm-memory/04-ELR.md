# 04 ELR：可调计算量的潜在递归语言模型

- 论文：[arXiv:2610.12582](https://arxiv.org/abs/2610.12582) · [官方 PDF](https://arxiv.org/pdf/2610.12582) · [本地 PDF](2610.12582.pdf)
- 日期：**2026-10-12 正式公告**；2026-10-08 提交。
- 作者：Faisal Ladhak、Shantanu Acharya、Santiago Akle Serano、Simeng Sun、Boris Ginsburg、Krishna C Puvvada。机构：NVIDIA（PDF 首页有公司标识、邮箱域名和版权署名，已核验）。
- 机构优先级：A（NVIDIA）；研究标签：latent recurrence、adaptive compute、LLM architecture。

1. **做了什么｜论文证据：**提出 Elastic Latent Recurrence，试图让共享层递归模型在一次循环时不付明显性能税，并可用更多循环换取精度。
2. **怎么做、实验如何设计｜论文证据：**结合门控、可学习步长、每次优化更新内混合循环深度，以及循环索引/预算条件化；MoE 复用首轮 expert 路由，推理只保留末轮 KV。以同数据非递归模型为匹配基线，测试 4B dense 与 30B-A3B MoE hybrid，并比较多任务质量与训练/推理开销。
3. **结论｜论文证据：**一循环与匹配模型接近，多循环带来额外收益；论文报告复用路由使混合深度更新耗时下降 11.7%，但收益需结合实际延迟与硬件测量看。
4. **未来影响｜我的推断：**单检查点的推理计算弹性可减少为不同预算训练多套模型的需求，也为潜在状态迭代提供工程范式。
5. **Critical thinking｜我的推断：**“无一次循环税”依赖匹配的训练数据、参数和预算定义；新增循环可能在真实服务下受同步/带宽限制。建议画出等训练 FLOPs、等推理延迟、等内存三种 Pareto 曲线，并测试长上下文及分布外任务。
6. **可信度：4/5。**依据：检查了训练配方、消融与两种模型规模的多任务结果；优点是公平匹配意识与成本分析，局限是更大规模和真实服务端延迟尚待证实。
