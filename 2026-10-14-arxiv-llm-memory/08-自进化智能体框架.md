# 08｜Self-Evolving Agent Harness：自进化智能体的框架与准入条件

- arXiv：[2610.18813](https://arxiv.org/abs/2610.18813)；[官方 PDF](https://arxiv.org/pdf/2610.18813)；本地 PDF：[2610.18813.pdf](2610.18813.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-13。
- 作者：Chuyang Wei、Haoxiang Guan、Minghang Zhu、Kexin Zhou、Jiyan He、Xiren Zhou、Huanhuan Chen、Yifei Shen。机构：Zhongguancun Academy、Zhongguancun Institute of AI、中国科学技术大学（PDF 首页署名）；机构优先级：**A｜一流高校/研究院**。研究标签：self-evolving agent、更新准入、保留性、理论框架；**弱相关但具启发性**（并非具体记忆算法）。

## 1. 做了什么

**论文证据：**把自进化 agent 的“更新目标、候选提案、准入规则”分离，讨论何时能在提升能力时控制旧能力损失与安全风险。

## 2. 怎么做、实验如何设计

**论文证据：**全文主要给出形式化定义、泛化/保留条件与框架组件；属于框架/理论讨论，不应把概念推导写成大规模实证结论。PDF 可读正文约 18 页；摘要中的篇幅描述与本地可获取版式不一致，故以实际 PDF 为准。

## 3. 结论

**论文证据：**可将自改动的接受条件明确化，并要求每次改动通过保留、泛化及风险检查。它未证明某个具体记忆实现必然有效。

## 4. 未来影响

**我的推断：**持久记忆写入/合并/删除也可视作更新提案，采用回归任务和安全检查作为准入门槛。

## 5. Critical thinking

**关键假设：**准入时可观测的测试覆盖部署分布。**区别：**提出更新治理框架而非单一自我改进算法。**失败情形：**代理优化测试、长期漂移、难以定义被保留的能力。**建议：**在公开 agent 记忆 benchmark 上实现具体 harness，报告旧任务保持率、失败回滚率和更新成本。

## 6. 可信度判断

**2/5（对经验效果）**。概念框架有启发，但当前 PDF 缺少与其广泛主张相称的独立实证验证；理论条件也不能直接保证现实部署。机构优先级独立标注。
