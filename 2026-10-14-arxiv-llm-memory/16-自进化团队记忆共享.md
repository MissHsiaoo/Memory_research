# 16｜AReaL-RSI：递归自改进团队的自适应扩展与协调

- arXiv：[2610.18083](https://arxiv.org/abs/2610.18083)；[官方 PDF](https://arxiv.org/pdf/2610.18083)；本地 PDF：[2610.18083.pdf](2610.18083.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-13。
- 作者：Wenhao Zhou、Jiajun Song、Haitao Wang、Zipeng Qiu、Yingqi Peng、Ruida Xu、Jiale Li、Wenshuang Li、Shusheng Xu、Wei Dong、Hao Dai、Tongkai Yang、Yi Gao、Binhang Yuan。机构：蚂蚁集团、浙江大学、香港科技大学（PDF 首页署名）；机构优先级：**A｜重点产业/一流高校**。研究标签：self-evolving agent、团队记忆、协调、算力扩展；与个人记忆为相邻主题。

## 1. 做了什么

**论文证据：**提出持久化的研究型 agent 团队，使不同角色能有条件地共享历史发现，并自适应分配调查工作。

## 2. 怎么做、实验如何设计

**论文证据：**AReaL-RSI 结合专门化角色、条件共享记忆和任务规模调度；在 Terminal Bench、KernelBench 及多个任务—骨干组合上评测，比较单纯增加 agent/运行预算的基线。全文讨论认为结果支持“信息复用与角色分化一起设计”，不能单独归因于记忆。

## 3. 结论

**论文证据：**Terminal Bench 在两个骨干上各提高 2.2 个百分点；KernelBench speedup 提高约 32.2–36.8%；报告七个任务—骨干组合的扩展比较。

## 4. 未来影响

**我的推断：**多 agent 记忆应区分团队共享知识、角色私有草稿与有条件可复用成果；盲目全共享可能放大噪声。

## 5. Critical thinking

**关键假设：**中间发现可迁移，且共享信息的收益超过通信开销。**区别：**联合设计团队组织与记忆路由。**失败情形：**错误发现被跨 agent 放大。**建议：**消融角色、共享门控和预算调度，追踪错误传播与真实 wall-clock 成本。

## 6. 可信度判断

**3/5。**有跨任务效果及扩展实验；多个组件耦合使单独记忆贡献不易辨认，部分增益较小。依据 PDF 方法/结果；机构与证据评价分离。
