# 07｜Reliable Memory from Unstable Growth：随机实验筛选智能体手册

- arXiv：[2610.18427](https://arxiv.org/abs/2610.18427)；[官方 PDF](https://arxiv.org/pdf/2610.18427)；本地 PDF：[2610.18427.pdf](2610.18427.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-13。
- 作者：Hoang Pham、Cong-Duy Nguyen、Dong Le、Ponhvoan Srey、Anh Tuan Luu。机构：南洋理工大学、VinUniversity（PDF 首页署名）；机构优先级：**A｜一流高校合作**。研究标签：self-written agent memory、经验筛选、随机实验、长程增长。

## 1. 做了什么

**论文证据：**研究 agent 自写 playbook 越长越不稳定的问题；提出 Randomized Block Curation（RBC），以小规模随机实验判定哪些经验块值得继续保留。

## 2. 怎么做、实验如何设计

**论文证据：**随机纳入/排除 playbook 块，用后续任务成功率估计每块在其他块背景下的边际收益；在两种记忆系统、三个 benchmark、三个开放模型上，与全量手册、无手册、agent 自行筛选比较。全文局限：需要额外练习回合和可观察任务结果，块强交互时退回整份手册选择；实践任务不似部署任务时保证减弱。

## 3. 结论

**论文证据：**报告平均成功率 RBC 66.9%，全量手册 55.5%，无手册 54.1%，agent 自筛选 53.8%。结果支持“经验数量 ≠ 经验质量”，但以额外试验成本换取可靠性。

## 4. 未来影响

**我的推断：**可把记忆写入机制做成可检验的因果特征选择；对价值为负的“心得”主动淘汰。

## 5. Critical thinking

**关键假设：**练习任务具有代表性、记忆块可分。**区别：**用随机纳入/排除的结果估值，而非让同一个 agent 依据文本直觉挑选。**失败情形：**强交互经验、罕见高风险任务、在线试错成本高。**建议：**报告单位额外回合收益，并测试训练/部署分布偏移和块间交互。

## 6. 可信度判断

**4/5。**随机化设计、多个基准与清楚的基线较强；仍受开放模型、块可分性和练习成本约束。依据 PDF 方法/实验/局限；机构级别不替代证据。
