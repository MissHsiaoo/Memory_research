# 14｜Memory Echo：记忆回声的生命周期评测与来源引导修复

- arXiv：[2610.17763](https://arxiv.org/abs/2610.17763)；[官方 PDF](https://arxiv.org/pdf/2610.17763)；本地 PDF：[2610.17763.pdf](2610.17763.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-13。
- 作者：Yufeng Li、Sheng Yao、Peng Zeng、Dezhang Kong、Shi Lin、Changting Lin、Xun Wang、Meng Han。机构：华东师范大学、USC、浙江大学、浙江工商大学（PDF 首页署名）；机构优先级：**A｜高水平高校合作**。研究标签：agent memory、错误传播、来源追踪、纠错。

## 1. 做了什么

**论文证据：**研究错误答案进入 agent 记忆后被多次引用而强化的“Memory Echo”，并提出来源家族引导的去重、校正优先级方法 FPA。

## 2. 怎么做、实验如何设计

**论文证据：**在受控历史位置植入来自其他问题的真实答案，回放 190 个问题×4 个框架；比较修复前后准确率和污染率。作者局限指出：这是受控播种，不能估计自然发生率；比较方法重放既有候选池；FPA 借助基准给定的来源/有效性标注，最终答案选择也贡献了增益；正确性由 GPT-5.6 裁判判断，边界样本无独立人工审计。

## 3. 结论

**论文证据：**DeepSeek/Kimi 条件下准确率由 0.825→0.920、0.782→0.916；污染率由 0.106→0.030、0.109→0.038。作者也说明收益依赖可用替代证据和确实存在的 Echo 冲突。

## 4. 未来影响

**我的推断：**记忆项应保留来源家族和修订关系；多个“相同答案”的条目不一定是独立证据。

## 5. Critical thinking

**关键假设：**来源家族/有效期标注足够可靠。**区别：**把错误传播当生命周期问题，而不只做单次检索去重。**建议：**在独立增长的真实记忆库中在线随机评测，加入人工审计和不完整来源标注压力测试。

## 6. 可信度判断

**3/5。**受控回放和多框架结果支持机制；人造播种、标注 oracle 与 LLM 裁判限制外部效度。依据 PDF 实验/局限；机构单独评价。
