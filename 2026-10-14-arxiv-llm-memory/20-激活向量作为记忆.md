# 20｜What Survives When Activation Steering Is Used as Memory

- arXiv：[2610.14958](https://arxiv.org/abs/2610.14958)；[官方 PDF](https://arxiv.org/pdf/2610.14958)；本地 PDF：[2610.14958.pdf](2610.14958.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-10。
- 作者：Vedant Jumle。机构：TU Delft（PDF 首页署名）；机构优先级：**A｜高水平研究型高校**。研究标签：LLM latent memory、activation steering、事实与倾向。

## 1. 做了什么

**论文证据：**把激活向量当作轻量记忆，区分它能保存“倾向”还是“具体事实”，并测试是否产生错误的偏好方向。

## 2. 怎么做、实验如何设计

**论文证据：**在冻结的 Qwen3.5 2B/9B 上，以少量手写跟进问题写入激活记忆，评估非相关回答是否保持不变、事实调用与好恶方向。作者局限：仅一个模型家族、41 个项目，部分“讨厌”结果只有 7–8 项；主要由同家族 LLM 裁判标注、无人工标签，跨家族裁判面板并非预注册；手写反义参照和单条记忆不代表真实系统。

## 3. 结论

**论文证据：**98% 非相关回答未改变，但干净事实使用最多约 15%，远低于 in-context 的 96–98%；某些反向参照会把 dislike 扭成 like。激活记忆对行为倾向可能比事实更适合。

## 4. 未来影响

**我的推断：**可将风格/倾向放入 latent state，把需精确核验的事实保留在可检索、可更新外部存储；不要混淆“可控行为偏置”和“可信事实记忆”。

## 5. Critical thinking

**关键假设：**小规模激活实验可代表多记忆、长时交互。**区别：**同时量测成功写入、事实保真及负向偏好翻转，给 latent memory 一条清晰失败边界。**建议：**多家族、多并存记忆、真人标签与自动选择反义参照实验。

## 6. 可信度判断

**3/5。**预注册设计和负面结果较有价值；样本、模型家族与裁判限制强，尚不能断言所有激活记忆都不适合事实。依据 PDF 实验/局限；高校机构优先级不代替证据质量。
