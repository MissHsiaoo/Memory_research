# 01｜Many Steps into One：推理压缩与安全记忆复用边界

- arXiv：[2610.17544](https://arxiv.org/abs/2610.17544)；[官方 PDF](https://arxiv.org/pdf/2610.17544)；本地 PDF：[2610.17544.pdf](2610.17544.pdf)
- 正式公告批次：2026-10-14（北京当日）；初次提交：2026-10-13。公告日期不等于提交日期。
- 作者：Jianghong Zhou、Hao Rong、Chen Lin、Daoan Zhang。
- 机构：ByteDance、Scale AI（PDF 首页署名）；机构优先级：**A｜重点产业研究机构**。研究标签：agent memory、过时知识、推理缓存、安全复用。

## 1. 做了什么

**论文证据：**研究 agent 把多步推理压缩成可复用记忆后，底层事实或代码要求变化造成的“过时答案”风险；区分可验证的证书式记忆与需要重新推理的情形。

## 2. 怎么做、实验如何设计

**论文证据：**构造知识图谱多跳事实编辑、Wikidata 时间限定词变化，以及 EvalPlus 代码需求/API 改动；比较复用策略和安全校验/失效策略。方法采用对失败更敏感的似然比加权，并在发现变化时重启推理。全文局限说明覆盖三个领域、五个最多 8B 的开放模型；每个实例—版本只解码一次，种子方差仅在子集测量，理论还假定每次审计提供已验证结果及随机事实变更。

## 3. 结论

**论文证据：**所比较的复用方法在多跳编辑事实中产生 7.0–13.5 倍过时答案，在有精确校验器的代码场景中达 35–73 倍；失效检测可显著压低过时输出。结论针对这些受控变化场景，不等同真实开放网络的事故率。

## 4. 未来影响

**我的推断：**持久记忆系统应保存来源、依赖和有效期，并把“命中记忆”与“允许直接答复”分成两道决策；编辑事实后的过时答复率比静态检索准确率更能暴露风险。

## 5. Critical thinking

**关键假设：**可识别事实依赖，且能获得可靠校验结果；现实中来源冲突、软知识和无真值任务可能不满足。**区别：**不是继续提高缓存命中率，而是量化推理压缩的安全代价。**可复现建议：**用同一编辑轨迹增加多种闭源/大模型、多次采样及无精确校验器的人工评估，报告安全性—延迟 Pareto 曲线。
