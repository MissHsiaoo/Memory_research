# 06｜VitaBench：超越检索的记忆生命周期

- arXiv：[2610.14731](https://arxiv.org/abs/2610.14731)；[官方 PDF](https://arxiv.org/pdf/2610.14731)；本地 PDF：[2610.14731.pdf](2610.14731.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-10。
- 作者：Muquan Yu、Dihan Hu。机构：香港大学、香港中文大学、Cornell University（PDF 首页署名）；机构优先级：**A｜一流高校**。研究标签：agent memory、生命周期管理、压缩/删除、benchmark。

## 1. 做了什么

**论文证据：**VitaBench 将记忆评测从“能否检索到”推进为“应当保留、压缩、合并还是删除”，要求代理为未来不确定任务做表示决策。

## 2. 怎么做、实验如何设计

**论文证据：**设计 Diagnostic 与 Naturalistic 两层任务，给出不同记忆操作的反事实后果；比较固定、短视和考虑延迟收益的策略，并与 LongMemEval、LoCoMo 等检索型基准的评测接口对照。全文讨论承认，在 Naturalistic 条件下现有策略与 oracle 仍存在 41.1 的效用差距。

## 3. 结论

**论文证据：**部分状态在短期与长期目标下的最优动作发生翻转（报告 60.2%/56.5%）；学习式延迟策略效用 101.5，固定策略 83.4。数字只在作者所定义的效用函数和环境中成立。

## 4. 未来影响

**我的推断：**长期 agent 的记忆管理算法需要测试不可逆的早期丢弃决策，而不能只在固定记忆快照上报告回答准确率。

## 5. Critical thinking

**关键假设：**基准的未来任务与效用权重能代表真实部署；人为设定的删除成本会影响动作优劣。**区别：**明确记录早期表示决策的长期反事实。**建议：**用真实用户授权的会话流复现 horizon reversal，并同时计入隐私、延迟与存储成本。

## 6. 可信度判断

**3/5。**评测定义清晰、有多种策略和反事实分析；其结论对效用设计及合成环境敏感，外部效度尚需真实部署。评分来自 PDF 评测与讨论，与机构分开。
