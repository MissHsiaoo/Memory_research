# 19｜When Skills Remain But Access Fails：因子化技能记忆

- arXiv：[2610.15492](https://arxiv.org/abs/2610.15492)；[官方 PDF](https://arxiv.org/pdf/2610.15492)；本地 PDF：[2610.15492.pdf](2610.15492.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-11。
- 作者：Haomiao Qiu、Yining Tang、Hongyi Wan、Changfeng Sun、Ziyue Qiao、Miao Zhang。机构：哈尔滨工业大学（深圳）、Great Bay University、浙江大学（PDF 首页署名）；机构优先级：**A｜高水平高校合作**。研究标签：continual learning、skill memory、LoRA、检索路由。

## 1. 做了什么

**论文证据：**指出技能持续内化不只会“技能消失”，还会出现技能仍在但寻址失败；提出 Factorized Skill Memory（FSM）分离访问与执行。

## 2. 怎么做、实验如何设计

**论文证据：**用可塑性地址记忆负责选取技能，用每阶段冻结的 LoRA 执行记忆保存技能；在五阶段 TaskBench 的 100 个技能上比较重放式和无重放隔离式持续学习。实验分别报告技能定位与精确执行。

## 3. 结论

**论文证据：**平均精确匹配 65.95%，寻址准确率 93.38%；比无重放隔离基线高 14.3 个百分点，距 Replay 基线 1.9 个百分点。这同时表明“找到技能”仍远不等于正确执行。

## 4. 未来影响

**我的推断：**agent 长期技能记忆应分别诊断检索路由、技能执行和阶段迁移，避免只用总体成功率掩盖寻址瓶颈。

## 5. Critical thinking

**关键假设：**技能可按阶段拆为冻结模块，且地址记忆能随新任务持续更新。**区别：**显式分离定位与执行记忆。**失败情形：**技能数量增长导致模块成本上升，复合技能跨模块协同困难。**建议：**扩至更长任务流，量测内存/延迟增长、跨技能组合及真实 agent 工具调用。

## 6. 可信度判断

**3/5。**定位与执行拆解、五阶段基线比较有价值；任务/技能规模和长期模块成本仍需验证。依据 PDF 方法/实验；机构优先级单独判断。
