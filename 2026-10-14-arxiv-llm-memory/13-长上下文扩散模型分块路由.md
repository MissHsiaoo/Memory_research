# 13｜Prefilling-dLLM v2：长上下文扩散语言模型的分块路由

- arXiv：[2610.17868](https://arxiv.org/abs/2610.17868)；[官方 PDF](https://arxiv.org/pdf/2610.17868)；本地 PDF：[2610.17868.pdf](2610.17868.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-13。
- 作者：Qi Han、Jing Xiong、Ziyuan Zhang、Ngai Wong。机构：香港大学、浙江大学（PDF 首页署名）；机构优先级：**A｜一流高校**。研究标签：diffusion LLM、long context、稀疏注意、路由。

## 1. 做了什么

**论文证据：**为长上下文 diffusion LLM 设计可学习的块路由，在 prefilling 阶段选择更有用的上下文块，降低密集注意成本。

## 2. 怎么做、实验如何设计

**论文证据：**以 mask token 路由槽、分块 top-K 选择上下文；在 Dream-v0-Base-7B 上用 RULER 16K–128K 长度评测，并与 NSA 和密集注意比较质量及速度。此工作侧重计算/访问效率，不直接解决用户记忆的真实性或删除。

## 3. 结论

**论文证据：**128K 下相对 NSA 报告 +7.4 个百分点；相对密集注意报告 172× 解码速度提升（论文特定实现和长度）。不能把该数字解释为端到端服务吞吐普遍提升。

## 4. 未来影响

**我的推断：**若长时记忆被放进超长上下文，块路由可成为 memory retrieval 与 diffusion 解码之间的计算桥梁。

## 5. Critical thinking

**关键假设：**选中的块覆盖答案所需信息；跨块推理可能需要多个弱相关块。**区别：**针对 diffusion prefilling 的 mask token 特征设计路由。**建议：**报告预填、解码和端到端延迟分项，测多跳记忆任务和漏召回最差分位数。

## 6. 可信度判断

**3/5。**长序列与质量/速度双指标有价值；主要在一个 7B 骨干和 RULER 体系，跨架构与真实部署外推有限。依据 PDF 方法/实验，非仅摘要。
