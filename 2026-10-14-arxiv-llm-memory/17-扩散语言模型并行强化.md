# 17｜A Few More Tokens Ahead：强化扩散语言模型并行生成

- arXiv：[2610.18200](https://arxiv.org/abs/2610.18200)；[官方 PDF](https://arxiv.org/pdf/2610.18200)；本地 PDF：[2610.18200.pdf](2610.18200.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-13。
- 作者：Jiahao Kuang、Yangfan Gao、Tao Gui、Yuanbin Wu、Qi Zhang、Xuanjing Huang、Tao Ji。机构：华东师范大学、复旦大学（PDF 首页署名）；机构优先级：**A｜高水平高校**。研究标签：diffusion LLM、并行解码、强化学习。

## 1. 做了什么

**论文证据：**RePara 训练扩散 LLM 同时可靠预测更多 token，针对并行解码一扩张准确率就跌落的“Parallelism Gap”。

## 2. 怎么做、实验如何设计

**论文证据：**用短 token 块的组相对强化学习，在 LLaDA/SDAR 等模型上测 GSM8K、MATH-500，并尝试代码任务。论文局限：训练 rollout 长度 256，评测不超过 512 token；数学收益未稳定迁移代码，直接应用可能降准确率；部分初始化对照缺少等额额外训练预算的比较。

## 3. 结论

**论文证据：**基线四模型在 16 token/step 条件下成功率低于 15%；RePara 在数学任务中优于 JustGRPO，并报告训练步层面的约 1.96× 加速。作者承认 8→16 token/step 时 LLaDA 准确率仍下降。

## 4. 未来影响

**我的推断：**扩散模型的效率应评价“速度×正确率”的实际可用吞吐，不宜只报告每步生成 token 数。

## 5. Critical thinking

**关键假设：**短块奖励可塑造长链联合正确性。**区别：**直接强化多 token 并行能力。**建议：**等算力训练对照、长推理/代码基准、端到端延迟及错误随并行度变化曲线。

## 6. 可信度判断

**3/5。**数学任务证据和限制披露充分；代码迁移不稳定、长序列和预算公平性尚未解决。依据 PDF 方法/实验/局限。
