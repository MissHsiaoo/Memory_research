# 05｜Online LLM Personalization from Pairwise Preferences Across Users

- arXiv：[2610.17203](https://arxiv.org/abs/2610.17203)；[官方 PDF](https://arxiv.org/pdf/2610.17203)；本地 PDF：[2610.17203.pdf](2610.17203.pdf)
- 正式公告批次：2026-10-14；初次提交：2026-10-12。
- 作者：Romain Puech、Georgy Salakhutdinov、Dimitris Bertsimas。
- 机构：MIT（PDF 首页署名）；机构优先级：**A｜一流高校**。研究标签：LLM personalization、在线学习、pairwise preference、跨用户迁移。

## 1. 做了什么

**论文证据：**提出 TutorDuel 基准与 CODuel：在用户只给成对偏好反馈时，利用历史用户学习群体先验，再快速个性化当前用户的 LLM 回复风格。

## 2. 怎么做、实验如何设计

**论文证据：**把选择建模为情境式 dueling bandit，在六种回答风格中学习；从已完成会话估计群体先验，比较随机选择、其他在线方法和逐用户线性 oracle，并使用未参与开发的学生/主题配置。全文局限明确：偏好反馈和参考效用主要来自同一 LLM 裁判；真人判断只有两位作者的 204 次比较，尚未量测真实满意度或教育成果；假设会话内偏好固定、总体平稳。

## 3. 结论

**论文证据：**相对随机成对选择，CODuel 降低 44–48% 的超额遗憾，但只达到逐用户线性 oracle 略过一半的表现；跨用户迁移对不同用户并非均等有益。

## 4. 未来影响

**我的推断：**个人记忆可存“偏好不确定性与反馈”，而非把单次点赞写成永久特征；在线系统应对漂移与群体迁移的负效应设防。

## 5. Critical thinking

**关键假设：**模拟裁判与人类长期偏好一致。**区别：**不是离线摘要历史，而是以成对反馈主动更新个性化策略。**失败情形：**教育上让学生喜欢的答案并非最有学习成效。**建议：**真人长期随机试验，同时量测用户满意、学习效果和偏好漂移，报告少数用户最差分位数。

## 6. 可信度判断

**3/5。**设计和基线较完整，论文也诚实列出假设；但核心效果在模拟裁判上建立，真实人群验证很少。依据 PDF 方法、实验、局限；MIT 署名不改变证据分。
