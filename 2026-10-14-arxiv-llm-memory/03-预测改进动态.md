# 03｜Predict Before You Modify：先预测再修改智能体

- arXiv：[2610.13991](https://arxiv.org/abs/2610.13991)；[官方 PDF](https://arxiv.org/pdf/2610.13991)；本地 PDF：[2610.13991.pdf](2610.13991.pdf)
- 正式公告批次：2026-10-14 的 cs.LG 官方 new 列表；arXiv 页面及 PDF v1 页脚显示 **2026-09-26**。这与 `2610` 编号的月份表面不一致，属来源元数据异常，不能自行推定原因；入选仅依据它确实列在当天官方 *New submissions* 第 6 项，而不是把提交日冒充公告日。
- 作者：Zixuan Xie、Chang Xu、Yuhua Jiang、Li Zhao。
- 机构：Microsoft Research、清华大学、University of Virginia（PDF 首页署名）；机构优先级：**A｜重点产业研究机构/一流高校**。研究标签：self-evolving agent、改进动态模型、长期学习；与记忆机制相邻。

## 1. 做了什么

**论文证据：**提出在执行自我修改前学习一个“改进动态模型”，预测候选改动效果，再决定哪些改动值得实际评估。

## 2. 怎么做、实验如何设计

**论文证据：**将以往修改及结果作为可编辑的 Improvement Dynamics Model（IDM）的依据，利用它预估改动后的表现，并在四个领域评估递归改进。此处的历史经验更接近元层面的过程记忆，而非用户个性化事实存储。

## 3. 结论

**论文证据：**论文报告四领域平均表现最高提高 46%；“最高”并不表示每个领域或预算下都有相同增益。

## 4. 未来影响

**我的推断：**agent memory 可从“记录做过什么”发展为“预测某种记忆操作会如何改变未来表现”，但需要防止预测模型固化旧环境偏差。

## 5. Critical thinking

**关键假设：**旧改动—结果样本可外推新任务。**区别：**把试错前置为可学习的效应预测。**失败情形：**分布漂移、验证反馈噪声、选择性观察导致 IDM 自我强化。**建议：**预注册修改预算，随机保留一部分未按 IDM 选择的候选作为对照，画出样本效率与灾难性回退曲线。

## 6. 可信度判断

**3/5。**有跨领域实验和明确机制；但最大提升不代表稳健平均效应，长期漂移与因果识别仍待检验。评分基于全文方法/实验；机构优先级另列。
