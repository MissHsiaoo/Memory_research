# 15. LIMBO: Lifelong Inference-Time Memory and Budget Optimization for LLM Agents

## 1. 做了什么（论文报告）

把是否使用记忆以及用多少计算量作为在线决策，而不是默认每次都检索。LIMBO针对终身任务流，在不改LLM参数的前提下，在准确率、回放长度和工具/推理预算之间学习权衡。

## 2. 方法与实验设计（论文报告）

采用双头LinUCB式contextual bandit，一头预测正确率、一头预测成本；12维特征包括提示长度、历史成本、近期成功/错误，选择无记忆、完整、压缩或检索回放及预算档位，任务结束用成败与成本更新。LAB的DB/OS各500任务，三个骨干Qwen2.5-7B、Llama3.1-8B、GPT-4o-mini，共六设置，每个三匹配种子。记忆池64条，检索权重由独立开发集选取；主控制器不做离线训练，但不等于全管线从无调参。

## 3. 结论与结果边界（论文报告）

相对每设置最高准确率的固定记忆基线，平均成本约降53%、最高82.8%。例如Qwen DB74.85→74.4、0.290→0.050美元等价成本；Llama DB70.0→66.2，存在3.8个百分点损失。Qwen DB无回放已经73.0且成本0.046，很多节省来自识别无须额外记忆，不能把headline理解为同准确率提升83%。

## 4. Future impact（我的推断）

与研究兴趣高度相关：将memory读取价值与token机会成本放到同一优化目标。可把latent压缩、向量检索、原文读取作为不同动作；不同用户任务的最优策略不一定相同，也不应只用召回率评价记忆模块。

## 5. Critical thinking（我的分析与建议）

每任务都有及时可靠的成败信号是重要条件，真实用户通常没有自动正确性标签。更根本地，当前动作会改变可存入记忆的成功轨迹，从而影响未来任务，contextual bandit忽略这层长期信用分配，可能偏向眼前便宜而放弃有价值的探索。建议测试延迟/噪声反馈、任务顺序打乱、同预算随机混合与固定最优策略，以及把是否写入与是否读取分开。

## 6. 可信度、优点与局限（主观评估）

3.5/5。优点：在线单遍、黑盒兼容、三种子、明确成本/准确率权衡，控制器CPU开销小。局限：仅两种环境，局部模型美元成本采用统一每百万token0.04/0.10的代理价格，不是实际GPU成本；约83%是相对选定固定基线，不能当普遍生产节省。没有验证无自动反馈的人类个性化场景。
