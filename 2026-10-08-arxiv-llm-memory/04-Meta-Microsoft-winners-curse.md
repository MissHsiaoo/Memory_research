# 04｜Meta/Microsoft：自我改进循环中的“赢家诅咒”

- 论文：[arXiv:2610.09239](https://arxiv.org/abs/2610.09239)｜[官方 PDF](https://arxiv.org/pdf/2610.09239)｜本地 `2610.09239.pdf`
- 正式公告：2026-10-08（cs.AI New submissions）；首次提交：2026-10-07 UTC，v1。作者/机构（PDF 首页）：Litao Hu（Meta）、Yutong Tang（Microsoft）。机构优先级：S；标签：self-improvement、评测偏差、agent evolution；弱相关但具启发性。

## 1. 做了什么

研究 self-improvement loop 中“从小验证集挑最好候选并持续接受”为什么会虚高。论文把每代候选的相关测量误差建模为选择偏差，并区分循环内部的选择集分数与真实 held-out 改善。这对自演化记忆特别重要：反复挑看似有效的记忆规则也可能只是在固定测试集上过拟合。

## 2. 怎么做、实验如何设计

用 Qwen 模型改写自身指令，每代产生四个候选；TREC-50、Banking77、GSM8K 任务都有与选择反馈隔离的 600-item held-out 集。PDF 包含探索性实验、预注册确认性实验、不同选择集规模和接受规则的比较，并考察 GEPA、MIPROv2 等优化器中的类似偏差。作者还尝试用未参与选择的 64 个样本估算起点到终点的无偏增益。

## 3. 结论

在 16 个选择样本时，最终选择集得分高出 held-out 准确率约 13–20 点；扩大到 256 个样本后仍高 1–5 点。不同任务的真实收益不一致，受测接受规则在整轮实验中未超越贪心接受。64 个新样本能消除平均报告偏差，但单次估计仍可能相差约 6 点。

## 4. 未来影响（推断）

自演化 agent 与 memory 系统应报告独立未来任务的增益及置信区间，把“接受新记忆策略”视作统计决策，而不是见到一次正分差就永久写入。

## 5. Critical thinking

实验主要是 prompt 自改进而非真实长期记忆，因此结果不能直接量化 memory contamination；但多轮复用同一验证集的机制完全相通。推荐在记忆系统中比较贪心、顺序检验、冷却期回滚与独立 holdout，并按用户分组避免同一人的重复问题泄漏。预注册增强可信度，但不同任务对候选相关性的敏感程度值得进一步分析。

## 6. 可信度：4/5

依据：已核查 PDF 的预注册设计、独立 held-out 协议和结果。优点是直接揭示演化评测的统计陷阱；局限是指令改写任务与真实多会话记忆差别较大，接受规则结论只覆盖已测预算与任务。
