# 13｜百度：MIRROR 让 LLM 内化用户偏好，而非只模仿参考文本

- 论文：[arXiv:2610.09795](https://arxiv.org/abs/2610.09795)｜[官方 PDF](https://arxiv.org/pdf/2610.09795)｜本地 `2610.09795.pdf`
- 正式公告：2026-10-08（cs.CL New submissions）；首次提交：2026-10-07 UTC，v1。作者/机构（PDF 首页）：Huayi Lai、Jicheng Yang、Min Yi、Chong Meng；Baidu Inc.。机构优先级：A+；标签：LLM personalization、self-distillation、preference internalization；直接相关。

## 1. 做了什么

个人化生成不应只复现用户历史文章的文风；更有价值的是在新问题上保持内容质量并体现偏好。MIRROR 用参考答案揭示偏好，却沿模型自己的生成轨迹蒸馏，使模型学习“在自己的输出上怎样更符合该用户”。

## 2. 怎么做、实验如何设计

核心为 reference-revealed on-policy self-distillation：在当前模型生成的 token 路径上，对齐无参考与有用户参考条件下的下一 token 分布；MIRROR-F 又对信息量大的参考 token 施加选择性监督，补足内容质量。PDF 在 LaMP 的新闻标题/论文主题与 LongLaMP 的摘要生成三任务上，用两种模型尺度、参考指标和 LLM 评审比较 SFT 等基线；另外留出三类未训练个性化生成任务检验灾难性遗忘与迁移。

## 3. 结论

论文报告 MIRROR/MIRROR-F 在三项个性化生成任务上有领先或更均衡的个性化与文本质量，并较 SFT 基线更少遗忘未见任务。摘要没有给可跨任务解释的单一增益数字，因此这里不虚构“平均提升百分比”。

## 4. 未来影响（推断）

若长期记忆能提供可追溯用户历史，个人化模型训练可把这些历史当“偏好教师”，从展示时拼接参考转向参数内化；但应保留更新和删除机制，避免旧偏好永久固化。

## 5. Critical thinking

隐含假设是用户历史文本真的代表当前偏好，且参考条件教师的判断可靠。论文强调内容质量，但评审模型可能偏爱某些写作风格；跨用户冷启动和偏好变化比静态数据更难。建议在同一用户的时间切片上测旧偏好失效、允许用户撤销历史参考，并通过盲评区分个人化收益与模板化改写。

## 6. 可信度：3/5

依据：核查 PDF 的 on-policy 蒸馏目标、三类主任务和 OOD 评测。优点是明确分离模仿与偏好内化，并测遗忘；局限是静态公开数据与 LLM judge 不能证明真实用户长期满意度，历史偏好的时效性也未解决。
