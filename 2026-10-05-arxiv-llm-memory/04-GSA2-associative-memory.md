# 04｜GSA2：线性注意力中的双侧关联记忆修正

- 论文：[arXiv:2610.02816](https://arxiv.org/abs/2610.02816)｜[官方 PDF](https://arxiv.org/pdf/2610.02816)｜本地：`2610.02816.pdf`
- arXiv 正式公告：2026-10-05；首次提交：2026-10-02。PDF 首页另标 ICLR 2027，不改变本次 arXiv 公告日期。
- 作者/机构：首页核验 Ruijie Li 等；HKUST (Guangzhou)、Tencent。
- 机构优先级：S；标签：latent memory、线性注意力、固定容量递归状态。关联性：直接。

## 1. 做了什么

GSA2 将键侧 Oja 修正与值侧 Delta 修正组合到共享隐槽位，意图解决固定容量线性注意力记忆的关联覆盖问题。

## 2. 怎么做、实验如何设计

作者设计带分离擦除/写入控制的 Gated Oja Rule-2，与 Gated Delta Rule-2 在两阶段更新中配合，并推导 chunkwise 并行训练。PDF 在约 1.3B 参数、100B FineWeb-Edu token 下测试纯递归和穿插滑窗注意力的混合架构；与 Transformer、Mamba-2/3、GDN、GSA、OJA 系列等比较，评测语言建模、常识、检索和长上下文，并做双侧修正消融。

## 3. 结论

论文报告 GSA2 在所测任务对强线性注意力基线有稳定优势，保持线性序列计算和常量大小的递归解码状态。这里的“记忆”是网络内部状态，不等同于用户长期记忆系统。

## 4. 未来影响（推断）

双侧可控擦写可启发 latent memory 的容量管理，但要证明跨会话个性化价值，还需任务级验证。

## 5. Critical thinking

应比较同精度/同吞吐下的内存带宽和 wall-clock，而非只看渐近复杂度。固定槽位能否保留罕见、低频但关键的用户偏好？建议在长周期冲突偏好、频繁更改资料、隐私删除任务上测读写干扰。

## 6. 可信度：4/5

依据：已读 PDF 公式、训练配置、基线与消融/结论。优点是同规模和多架构比较；局限是主要验证基础建模与检索，真实长时个体记忆迁移仍属推断。
