# 15｜Ansatz：数学研究 Agent 的持续图记忆

- 论文：[arXiv:2610.02945](https://arxiv.org/abs/2610.02945)｜[官方 PDF](https://arxiv.org/pdf/2610.02945)｜本地：`2610.02945.pdf`
- arXiv 正式公告：2026-10-05；首次提交：2026-10-02。
- 作者/机构：首页核验 Junyi Zhang 等；University of California, Los Angeles。
- 机构优先级：A+；标签：self-evolving agent memory、图记忆、科研 Agent。关联性：直接。

## 1. 做了什么

Ansatz 为长时数学探索建立跨问题图记忆，保存事实、计划、反例及依赖边，把失败与局部证明结构保留下来供后续重用。

## 2. 怎么做、实验如何设计

系统做依赖感知局部检索、证据敏感的研究前沿整理，以及对旧结论的限定召回并重新证明。PDF 在 First Proof Second Batch 的全部 10 题对照 Danus、Codex 和普通 GPT-5.6 Sol；因已有公开解答，测试时关闭 web search。作者报告 10/10 完成，还做四项组件研究；在四题消融中，独立验证器改为自审从 4/4 降至 2/4，移除策略咨询降至 1/4。论文另声称解决多个公开数学猜想，这些属于作者报告，尚非本报告独立验证。

## 3. 结论

结构化保存探索中间物与独立核验在该数学 Agent 设置有显著价值；对开放猜想的正确性不能仅凭论文宣称下结论。

## 4. 未来影响（推断）

科研 Agent 记忆或需“可审计证明依赖图 + 失败反例库”，不是纯文本摘要。

## 5. Critical thinking

10 题样本小、公开答案带来潜在训练污染，即使关 web 也不能完全排除模型预训练见过答案。应由独立数学家形式化复核开放问题证明、运行新鲜未公开题、计入所有并行 Agent 计算成本，并审计自审错误进入图后是否放大。

## 6. 可信度：2/5

依据：已读 PDF 测试协议与消融；组件价值的证据较清楚，但最强的“新数学成果”需要独立形式化验证。低分反映证据边界，不反映 UCLA 机构等级。
