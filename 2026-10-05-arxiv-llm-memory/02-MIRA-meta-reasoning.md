# 02｜MIRA：长程研究 Agent 的元推理

- 论文：[arXiv:2610.02525](https://arxiv.org/abs/2610.02525)｜[官方 PDF](https://arxiv.org/pdf/2610.02525)｜本地：`2610.02525.pdf`
- arXiv 正式公告：2026-10-05；首次提交：2026-10-01。
- 作者/机构：首页核验 Ankur Samanta 等；Meta AI、Columbia University、Tel Aviv University。
- 机构优先级：S；标签：self-evolving agent、持久研究记录、元推理、长程信用分配。关联性：直接。

## 1. 做了什么

MIRA 把“下一步研究什么”从冗长执行轨迹中抽离，作为独立可学习决策；研究记录持续保存，执行器每轮重新启动，以减少旧上下文干扰。

## 2. 怎么做、实验如何设计

外环从持久记录整理证据、下达 work order，内环执行一次调查；每个元决策边界训练生成式 critic 预测剩余回报，MIRA-AC 在此粒度训练 actor-critic。论文在定理证明及神经架构研究任务中先测试未训练架构，再用代理 hill-climbing 反馈训练，并在四个 autoresearch 环境评估黄金指标、跨环境初始化和 token 级对照。

## 3. 结论

论文直接证据支持：元决策粒度比直接优化长执行轨迹更便于预测价值与分配计算；训练后的 MIRA-AC 在所测环境提高最终表现。

## 4. 未来影响（推断）

长程科研 Agent 的记忆可从“所有事件都塞入上下文”转向“持久研究状态 + 决策边界的选择性回忆”。

## 5. Critical thinking

方法依赖固定的证据整理器与执行器：若整理器漏掉关键失败证据，actor 再强也无法纠正。论文局限章节明确承认这一点。应做“错误/缺失研究记录”压力测试、跨领域迁移，以及同总算力下与更强内环执行器比较；警惕过早放弃已有假设的探索偏差。

## 6. 可信度：4/5

依据：已查 PDF 架构、四环境实验与专门局限章节。优点是决策边界清楚、包含跨环境对照；局限是策划、检索和执行未共同学习，真实科研长期收益尚未独立验证。机构等级与证据可信度独立。
