# 19｜学到事实 ≠ 学到如何检索该事实

- 论文：[arXiv:2610.03251](https://arxiv.org/abs/2610.03251)｜[官方 PDF](https://arxiv.org/pdf/2610.03251)｜本地：`2610.03251.pdf`
- arXiv 正式公告：2026-10-05；首次提交：2026-10-02。
- 作者/机构：首页核验 Chaemin Jang 等；KAIST。
- 机构优先级：A+；标签：in-context retrieval、latent memory、知识更新。关联性：直接。

## 1. 做了什么

论文将“事实本身写进模型”与“学会通过不同提问形式把事实读出来”分开，解释相同知识在陈述句可答、在短键值提示却答不出的现象。

## 2. 怎么做、实验如何设计

两阶段控制实验：第一阶段一组模型在五种 request form 上学习旧事实，另一组只见陈述；第二阶段两组用同样的陈述形式学习全新事实。随后在八种形式上测 300 个目标事实及 2,000 候选首位检索，主要比较采用配对八种子。作者检查答案前隐状态的 context state，并在推理或训练时进行状态替换，观察检索是否被恢复/抑制。

## 3. 结论

此前的“如何提问”经验会影响后来新知识的可检索性；只比较事实写入成功率会低估接口形式的作用。

## 4. 未来影响（推断）

LLM memory 系统评测应同时记录写入正确率与不同请求形式的读取覆盖率；长时用户记忆可能需要检索接口的持续训练。

## 5. Critical thinking

控制事实训练便于识别机制，但与自然对话中渐进、含糊、矛盾知识不同。PDF 局限指出该 context state 不能解释所有遗忘，预训练背景也会影响效应。建议以真实用户事实、跨语言提问和参数/外部记忆混合系统复现，并测状态干预是否损伤其它知识。

## 6. 可信度：4/5

依据：已读 PDF 两阶段设计、配对种子、干预和局限；作者称代码、提示及逐格结果可用。优点是因果控制较强；局限是受控知识世界的外部效度。
