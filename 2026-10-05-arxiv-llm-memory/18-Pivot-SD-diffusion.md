# 18｜Pivot-SD：只训练扩散去噪中的关键承诺

- 论文：[arXiv:2610.03665](https://arxiv.org/abs/2610.03665)｜[官方 PDF](https://arxiv.org/pdf/2610.03665)｜本地：`2610.03665.pdf`
- arXiv 正式公告：2026-10-05；首次提交：2026-10-02。
- 作者/机构：首页核验 Seo Hyun Kim 等；KAIST AI、University of Toronto、Vector Institute。
- 机构优先级：A+；标签：diffusion LLM、去噪信用分配、自蒸馏。关联性：直接。

## 1. 做了什么

Pivot-SD 不对扩散模型整段最终文本平均监督，而只挑出显著降低剩余掩码位置不确定性的去噪“枢纽” token。

## 2. 怎么做、实验如何设计

计算一次承诺对其余位置熵的减少，成功轨迹的枢纽用交叉熵训练，失败轨迹仅对其枢纽施加 unlikelihood。PDF 以 LLaDA-8B-Instruct 为主，每项数学/代码任务选 200 个问题、每题 4 条 rollout，数学用答案匹配、代码用单测判成功；在 GSM8K、MATH-500、HumanEval+、MBPP+ 比较完整序列 SFT 与预算相近扩散 RL，并报告第二个同量级掩码扩散骨干。

## 3. 结论

论文报告在小后训练预算下，局部枢纽监督优于所列完整 SFT 和预算匹配 RL 基线；这证明某些早期承诺较重要，但不是所有扩散模型的最优训练法。

## 4. 未来影响（推断）

可启发 Agent 的经验选择：记忆只保存改变后续分布的少数关键决策，而非全轨迹无差别压缩。

## 5. Critical thinking

“信息增益高”未必意味着“对任务正确性因果重要”；高熵变化可能由格式 token 引起。应做随机/因果删减对照、跨块长推理、更多规模和真实推理延迟测试。PDF 局限指出超参数逐配置设置、只在块内定义枢纽，规模外推仍未解决。

## 6. 可信度：3/5

依据：已查 PDF 数据预算、基线、验证规则与局限。优点是实验预算清晰、包括成功和失败轨迹；局限是样本 200 题/任务、参数/骨干覆盖有限。
