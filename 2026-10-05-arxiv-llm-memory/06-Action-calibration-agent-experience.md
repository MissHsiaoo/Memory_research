# 06｜Action Calibration：为何历史记录未变成经验

- 论文：[arXiv:2610.02769](https://arxiv.org/abs/2610.02769)｜[官方 PDF](https://arxiv.org/pdf/2610.02769)｜本地：`2610.02769.pdf`
- arXiv 正式公告：2026-10-05；首次提交：2026-10-02。
- 作者/机构：首页核验 Jingyu Liu 等；Renmin University of China、ByteDance。PDF 未写 Seed，因此不标 Seed。
- 机构优先级：S；标签：self-evolving agent memory、行动—结果绑定、经验选择。关联性：直接。

## 1. 做了什么

论文指出保留完整交互历史并不意味着 Agent 会将过去动作与环境反馈正确配对；提出显式结果标注和学习式 calibrator 来记录有用经验。

## 2. 怎么做、实验如何设计

先对历史做删除、仅保留观察、动作顺序打乱等干预，再比较成功率；随后将每条观察明确标为前一动作的结果，最后训练选择性经验校准器。PDF 在 ALFWorld、ScienceWorld、WebShop、AppWorld 及五种模型做测试；历史干预表中总体 Raw 46.39%，Shuffle-All 46.75%，显示简单“动作顺序存在”并非有效利用历史的充分条件。作者还报告结果标注降低重复动作、校准器进一步提升恢复。

## 3. 结论

有些历史收益来自观察本身而非行动—结果推断；让因果对应关系更显式，比单纯扩大上下文更有用。

## 4. 未来影响（推断）

Agent 记忆写入单元或应是“动作、观察、结果解释、置信度”，并有拒收无效经验的机制。

## 5. Critical thinking

Shuffle-All 略高于 Raw 的总平均值可能涉及任务异质性或噪声，不能直接断言模型完全不理解行动因果。需要按环境/模型的配对置信区间、动作冲突用例、不可观测环境的控制实验；校准器也可能把错误解释永久写入记忆，应加入可撤销性和外部反馈审计。

## 6. 可信度：3/5

依据：已查 PDF 干预设计、表格与结论。优点是反直觉干预有诊断价值；局限是因果机制仍依赖实验设定，校准器跨环境泛化和误写率需进一步验证。
