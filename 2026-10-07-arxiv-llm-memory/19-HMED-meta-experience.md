# 19｜HMED：从技能修订的后果学习“如何改进技能”

- 论文：[arXiv:2610.07979](https://arxiv.org/abs/2610.07979)｜[官方 PDF](https://arxiv.org/pdf/2610.07979)｜本地 `2610.07979.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-06（UTC）。
- 作者/机构（PDF 首页）：Qianhan Feng 等；Chinese University of Hong Kong、Shanghai Jiao Tong University、Shanghai Innovation Institute。机构优先级：A（强研究型高校）；标签：self-evolving agent memory、meta-experience；直接相关。

## 1. 做了什么

把 Agent 的“元技能”（如何发现、修改任务技能）本身变成可学习对象，避免仅凭分支最终成绩判断某次修订好坏。

## 2. 怎么做、实验如何设计

HMED 回到修订发生前的相同发现状态，分别重新运行旧/新元技能，将同条件下的差异蒸馏为结构化 Meta-Experience；即使新修订最终未保留，也提取可复用的学习信号。PDF 在三个交互式 Agent 基准，跨开放和闭源模型比较技能发现表现与强基线。

## 3. 结论

控制初始发现状态后，修订后果比原始分支结果更能指导元技能改进；但重放状态仍不代表真实世界可完全复现。

## 4. 未来影响（推断）

自进化记忆应记录“我为何修改了技能、修改导致了什么”，而非只存最新版技能；失败的修订亦可提供负经验。

## 5. Critical thinking

同状态重放依赖可复现环境，真实工具与人类反馈常非确定性。建议跨随机种子、成本受限重放、环境漂移与多轮累积误差测试，并给元经验增加来源及失效期限。

## 6. 可信度：4/5

依据：已读 PDF 同起点配对重放、三基准和多模型评估。优点是改善经验的因果可比性；局限是重放与线上非平稳环境有落差。
