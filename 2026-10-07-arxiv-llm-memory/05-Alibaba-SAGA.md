# 05｜SAGA：从轨迹到可验证适用条件的抽象原则

- 论文：[arXiv:2610.06964](https://arxiv.org/abs/2610.06964)｜[官方 PDF](https://arxiv.org/pdf/2610.06964)｜本地 `2610.06964.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-03（UTC）。
- 作者/机构（PDF 首页）：Bowen Ye 等；Alibaba Group、Shanghai Jiao Tong University、USTC。机构优先级：S；标签：self-evolving agent memory、knowledge abstraction；直接相关。

## 1. 做了什么

将具体交互经验逐层提炼为可复用的程序和原则，并保存原则的适用条件及其证据来源，使 Agent 在新任务中不只机械套用旧轨迹。

## 2. 怎么做、实验如何设计

SAGA 先从轨迹生成情节描述、程序、原则，再按当前任务把检索到的原则具体化；原则导出的检查可对候选动作反馈、重采样。PDF 在 ScienceWorld 与 ALFWorld 比较性能，并消融“情境化实例化”和“行动约束”组件。

## 3. 结论

论文基准支持层次化经验抽象及执行—抽象闭环的价值；但“原则”能否跨完全不同任务领域稳健迁移未被充分验证。

## 4. 未来影响（推断）

Agent 记忆可以从事实仓库发展为附带证据链和适用范围的“可执行知识”，减少过度泛化。

## 5. Critical thinking

LLM 生成的原则可能看似通用实则来自偶然成功。建议做跨环境反事实测试、原则冲突处理、来源失效后的撤回和独立测试任务上的净收益分析。

## 6. 可信度：3/5

依据：已读 PDF 层级表示、双环境实验与组件消融。优点是保留原则到执行证据的联系；局限是环境覆盖和原则真实性验证有限。
