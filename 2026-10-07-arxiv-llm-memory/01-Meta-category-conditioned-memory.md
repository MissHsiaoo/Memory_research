# 01｜Meta：按语义类别决定哪些用户记忆不该写入

- 论文：[arXiv:2610.07100](https://arxiv.org/abs/2610.07100)｜[官方 PDF](https://arxiv.org/pdf/2610.07100)｜本地 `2610.07100.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-05（UTC）。
- 作者/机构（PDF 首页）：Olukunle Owolabi、Pulkit Gupta、Fei Wang；Meta AI。机构优先级：S；标签：personalized memory、agent memory write gate；直接相关。

## 1. 做了什么

研究长期用户记忆的写入门槛：同样的抽取置信度，对“价值观/信念”等推断性内容与直接陈述的事实不应一视同仁。

## 2. 怎么做、实验如何设计

在生产冷启动管线的形式下，以 100 个合成 persona、4,715 条候选断言评估来源支持度；对不同语义类别设置不同保留阈值，再与全局阈值比较。PDF 报告价值/信念断言仅 77.9% 获来源支持，其他类别为 96.2%；只提高价值观类门槛，未支持写入由 6.2% 降至 4.0%，并在可比保留率下多保留约 13 个百分点的估计覆盖率。

## 3. 结论

“是否写入”是记忆可靠性的独立决策；按类别校准比统一置信阈值更能处理推断性用户画像。论文自己强调方法尚只在合成数据上评测，不能当作真实用户部署效果。

## 4. 未来影响（推断）

个人助理可把推断性画像、明确陈述和临时计划分开管理，让高风险推断需要更强证据或用户确认。

## 5. Critical thinking

作者的支持度与覆盖率由 LLM judge 判定，绝对阈值依赖评审模型；类别误标会系统性丢失合法记忆。建议真人标注、跨文化偏好语料、下游行为损害测试，并给用户提供“查看/拒绝被推断价值观”的接口。

## 6. 可信度：3/5

依据：已读 PDF 方法、重复留出测试和明确局限。优点是写入边界问题定义清晰；局限是单一合成语料、LLM 评审及缺乏真实用户下游验证。
