# 02｜Meta：利用跨平台历史的个人 Agent 推荐调解

- 论文：[arXiv:2610.07588](https://arxiv.org/abs/2610.07588)｜[官方 PDF](https://arxiv.org/pdf/2610.07588)｜本地 `2610.07588.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-06（UTC）。
- 作者/机构（PDF 首页）：Yu Xia、Jiangfan Zhang、Jun Xiao、Julian McAuley、Xiangjun Fan；UC San Diego、Meta AI。机构优先级：S；标签：LLM personalization、personal agent、cross-platform memory；直接相关。

## 1. 做了什么

提出“平台推荐器 + 用户持有的个人 LLM Agent”协作范式：Agent 用获授权的跨平台历史修正候选排序，同时避免把平台原本正确的推荐错误覆盖。

## 2. 怎么做、实验如何设计

MediateRec 包括可扩展的代理跨平台环境和受控信息边界下的真实跨平台测试。PAMO 通过反事实遮蔽用户历史估计其调解价值，再在平台相对价值底线下重分配排序优势；PDF 比较结果导向 RL、见过与未见过的平台，并同时统计有益挽救与有害覆盖。

## 3. 结论

跨平台历史可帮助个人 Agent 纠正平台盲区，但强模型也会发生有害覆盖；PAMO 在论文基准中比匹配的 outcome-only RL 更好平衡两者。这里的受控跨平台测试不等于长期真人满意度实验。

## 4. 未来影响（推断）

若用户授权历史可跨服务携带，个性化主导权可能从单个平台迁向用户侧 Agent；同时需要严格的数据最小化与撤销机制。

## 5. Critical thinking

反事实遮蔽历史只能估计边际关联，未必识别真实因果偏好；跨平台数据也可能泄露敏感属性。应测授权撤回、偏好漂移、少数用户伤害、长期排序多样性及 Agent 与平台目标冲突。

## 6. 可信度：4/5

依据：已读 PDF 形式化定义、代理与受控真实测试、消融和跨平台评测。优点是正面报告 harmful overrides；局限是实际用户授权和长期满意度仍需部署验证。
