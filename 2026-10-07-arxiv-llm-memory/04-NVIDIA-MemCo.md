# 04｜MemCo：局部与全局记忆协作，面向未见环境

- 论文：[arXiv:2610.07376](https://arxiv.org/abs/2610.07376)｜[官方 PDF](https://arxiv.org/pdf/2610.07376)｜本地 `2610.07376.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-05（UTC）。
- 作者/机构（PDF 首页）：Xinting Liao 等；University of British Columbia、Vector Institute、NVIDIA。机构优先级：S；标签：agent memory、experience transfer；直接相关。

## 1. 做了什么

让多个 Agent 在不同环境中共享可迁移经验，同时保留各自环境的局部细节，减少对未见场景的重复探索。

## 2. 怎么做、实验如何设计

MemCo 设局部/全局两层记忆：局部保存环境具体轨迹，全局抽象可复用流程；执行时根据当前状态和决策阶段路由。PDF 在交互式决策基准比较孤立记忆、普通共享记忆等，并区分熟悉与留出环境布局；报告任务成功与探索步数，附结构消融。

## 3. 结论

两层记忆与阶段感知路由在所测交互环境中提高迁移表现、减少冗余探索，但不能保证跨差异更大的真实环境有效。

## 4. 未来影响（推断）

团队 Agent 可共享“操作原则”而不共享全部用户/环境原始轨迹，形成更可控的经验迁移层。

## 5. Critical thinking

全局工作流若抽象过度，会掩盖环境特定约束；共享池也可能传播错误策略。应报告跨环境负迁移、不同记忆池规模、经验隐私隔离与新环境冷启动曲线。

## 6. 可信度：4/5

依据：已读 PDF 局部/全局设计、留出布局比较与消融。优点是明确控制记忆粒度；局限是主要证据仍来自有限交互基准。
