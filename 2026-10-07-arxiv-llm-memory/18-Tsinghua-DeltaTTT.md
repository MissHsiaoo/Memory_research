# 18｜DeltaTTT：对非线性循环记忆逐层进行测试时优化

- 论文：[arXiv:2610.08553](https://arxiv.org/abs/2610.08553)｜[官方 PDF](https://arxiv.org/pdf/2610.08553)｜本地 `2610.08553.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-06（UTC）。
- 作者/机构（PDF 首页）：Yining Li、Dongchen Han、Jie Fu、Gao Huang；Tsinghua University、IQuest Research。机构优先级：A（顶尖高校研究组）；标签：latent memory、test-time training、recurrent memory；直接相关。

## 1. 做了什么

检验“状态依赖的顺序更新一定更适合记忆”这一直觉，发现非线性记忆里固定基点的并行训练有时反而更强，并提出更易优化的 DeltaTTT。

## 2. 怎么做、实验如何设计

把两层记忆网络的联合内循环优化改为逐层局部预测目标和状态依赖 delta rule，仍保留非线性读取并支持分块并行。PDF 在 DeltaNet、LaCT 底座测试语言建模和检索，相对各自循环基线报告改进；先导实验比较非线性记忆的顺序与固定基点并行更新。

## 3. 结论

非线性 latent memory 的瓶颈可能是优化难度，而不仅是容量或是否顺序更新。当前证据不等于开放域长期用户记忆有效。

## 4. 未来影响（推断）

设计可训练的隐状态记忆时，应同时考虑写入规则、训练并行性和单遍优化稳定性。

## 5. Critical thinking

改善语言建模/检索并不必然改善可控更新、事实撤销或用户身份隔离。建议在同等参数/FLOPs 下测长跨度更正、冲突记忆和连续个性化任务，并公开更新稳定性分布。

## 6. 可信度：3/5

依据：已读 PDF 反直觉先导实验、逐层更新算法及两类底座。优点是识别优化机制；局限是下游真实记忆任务覆盖有限。
