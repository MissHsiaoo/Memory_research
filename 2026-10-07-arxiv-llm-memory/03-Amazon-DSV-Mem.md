# 03｜Amazon AGI：专业工作流中的稠密、有状态视觉记忆基准

- 论文：[arXiv:2610.08102](https://arxiv.org/abs/2610.08102)｜[官方 PDF](https://arxiv.org/pdf/2610.08102)｜本地 `2610.08102.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-06（UTC）。
- 作者/机构（PDF 首页）：Jike Zhong 等；Amazon AGI、University of Southern California。机构优先级：S；标签：multimodal agent memory、benchmark；直接相关。

## 1. 做了什么

提出 DSV-Mem，检验多模态助理能否追踪专业文档/图表在长对话中的版本、权威来源和状态变更，而不是仅从静态图片回忆信息。

## 2. 怎么做、实验如何设计

基准有专家复核的场景与 1,000 个问题，分当前状态、过去状态、派生状态、变化历史、冲突/拒答五类；生成管线将状态转移构造与对话填充分开。PDF 测 27 个前沿/开源模型与记忆管理配置；最强基线得分仍低于 45%，分析认为治理性状态更新数量比原始长度、OCR 或算术更能解释难度。

## 3. 结论

专业视觉记忆的核心瓶颈是状态一致性和来源权威核验，单纯增加推理强度或一般记忆管理收益有限。作者明确说基准为研究者构造，不代表真实工作流分布。

## 4. 未来影响（推断）

评测个人/企业助理应从“是否记住文档”转向“是否知道哪个版本有效、谁有权覆盖、何时拒答”。

## 5. Critical thinking

低于 45% 可能部分来自基准生成过程或特定评分口径。建议在固定真实工作流日志上外部验证、逐类报告人类上限，并测试可审计的状态账本与来源冲突处理；不要把作者的自建基准分数等同部署失败率。

## 6. 可信度：4/5

依据：已读 PDF 基准构造、27 配置和局限。优点是把状态变化做成可测对象；局限是样本量和生成场景的外部效度有限。
