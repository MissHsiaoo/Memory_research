# 11｜ReFold：可逆的长程 Agent 跨轮上下文折叠

- 论文：[arXiv:2610.07863](https://arxiv.org/abs/2610.07863)｜[官方 PDF](https://arxiv.org/pdf/2610.07863)｜本地 `2610.07863.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-06（UTC）。
- 作者/机构（PDF 首页）：Yupeng Su 等；UC Santa Barbara、Intel。机构优先级：S（大型产业研究团队参与）；标签：agent context memory、long-horizon agent；直接相关。

## 1. 做了什么

在不永久删除历史的前提下缩短每轮发送给 Agent 的上下文，降低长程任务的 token 与 KV 缓存成本。

## 2. 怎么做、实验如何设计

ReFold 只改变渲染给模型的历史：已在早期轮次展示过的内容用占位符替代，Agent 明示已完成的轮次折成一行；底层完整历史保留，错误折叠可恢复。PDF 在五个长程基准、两个前沿模型和并发服务负载下比较成功率、token、KV、排队时间；报告最高 2.5 倍 token 降幅、单会话 KV 约减半，且未见所测成功率下降。

## 3. 结论

可逆渲染层能显著降低特定长程 Agent 负载的上下文开销；“最高”收益不代表所有任务、所有服务配置都相同。

## 4. 未来影响（推断）

记忆系统可把“完整可恢复原始历史”和“当前模型可见的压缩视图”分离，降低错误摘要的不可逆风险。

## 5. Critical thinking

“Agent 自报已完成”可能错误；恢复又增加延迟。应测试恶意/错误完成标记、被折叠事实的再调用、长会话累积恢复频率和等硬件并发公平比较。

## 6. 可信度：4/5

依据：已读 PDF 折叠算法、五基准及系统成本分析。优点是可逆性和真实服务指标；局限是触发恢复的风险在极端任务下仍需测。
