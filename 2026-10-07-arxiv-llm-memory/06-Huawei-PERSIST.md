# 06｜PERSIST：跨会话语音助理的“谁、什么、何时”记忆

- 论文：[arXiv:2610.07725](https://arxiv.org/abs/2610.07725)｜[官方 PDF](https://arxiv.org/pdf/2610.07725)｜本地 `2610.07725.pdf`
- 正式公告：2026-10-07；首次提交：2026-10-06（UTC）。
- 作者/机构（PDF 首页）：Achira Lin、Siyuan Hou 等；Tsinghua University、Huawei Technologies。机构优先级：S；标签：personalized memory、spoken dialogue、temporal memory；直接相关。

## 1. 做了什么

让共享语音助理跨会话辨认发言人、找回过去事件，并分辨原计划和后续修订。

## 2. 怎么做、实验如何设计

PERSIST 将历史整理为可读事件记录，以语义内容、声学说话人身份和时间状态的 3W 联合评分检索；复用对话底座的中间表示避免重复编码音频。论文新建 SpokenTrace，按记忆任务和说话人查询类型细分；报告端到端任务准确率 85.08%，all-support EM@3 从 BGE-large 的 49.01% 提到 82.10%，检索延迟由 578.42ms 降至 7.03ms。

## 3. 结论

语音记忆不能只做语义相似检索；说话人和时间状态是关键维度。数字属于作者的 SpokenTrace 与所测系统配置。

## 4. 未来影响（推断）

家庭/会议助理若要安全地长期个性化，必须把“谁说的、何时有效”作为记忆对象，而不是把多人信息合并成一个用户画像。

## 5. Critical thinking

说话人识别错误会造成严重跨用户泄漏。建议测试声音相似、变声、设备迁移、说话人撤回授权与纠错后记忆重算；报告按人群分层的识别误差及隐私事件。

## 6. 可信度：4/5

依据：已读 PDF 3W 机制、基准设计、对照与时延。优点是联合评估身份/时间/内容；局限是现实多人场景和隐私风险仍需长期验证。
