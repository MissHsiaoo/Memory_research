# 07｜Sakana AI：分离短时计算与长时保存的连续记忆机器

- 论文：[arXiv:2610.07907](https://arxiv.org/abs/2610.07907)｜[官方 PDF](https://arxiv.org/pdf/2610.07907)｜本地 `2610.07907.pdf`

## 1. 做了什么

针对单一循环状态同时承担短时计算和长期保持的瓶颈，提出显式分工的 Continuous Memory Machine（CMM）。

## 2. 怎么做、实验如何设计

在 Continuous Thought Machine 上增加矩阵形式的短、长时记忆；短时状态跟踪近期神经活动，长时状态保留可复用信息，Transformer 共同更新并双向读写两者。PDF 比较多种记忆增强网络，在算法、ICL 与循环推理任务评估泛化，也检查注意力模式。

## 3. 结论

在所测合成/结构化任务，分离两种状态有利于记忆与推理能力；尚不能据此断言开放域 LLM 的跨月个人记忆也能稳定写入。

## 4. 未来影响（推断）

Latent memory 架构可把快速工作记忆与较慢的持久状态区分，并设计双向更新而非统一压缩向量。

## 5. Critical thinking

更大矩阵状态可能只是增加容量和计算预算。应控制状态维度/FLOPs，做长距离事实修改、遗忘、隐私擦除及非合成语言任务，并测可解释注意力与真实内容可恢复性的关系。
