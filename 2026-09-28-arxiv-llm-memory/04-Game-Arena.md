# 04. Game Arena

- arXiv：[2609.31473](https://arxiv.org/abs/2609.31473)
- 提交日期：2026-09-25；正式公告批次：2026-09-28（cs.AI new）
- 作者/机构（PDF 末尾贡献说明核验）：Google DeepMind、Kaggle、Google Cloud Office of the CTO
- 机构优先级：**S｜顶级工业研究机构**
- 研究标签：弱相关但具启发性、agent evaluation、online adaptation、dynamic benchmark
- 本地 PDF：[2609.31473.pdf](./2609.31473.pdf)

## 1. 做了什么

构建持续扩展的 Kaggle Game Arena，让 LLM 在棋类、扑克和狼人杀中直接对战，以动态对手分布替代容易饱和和污染的静态题库。与记忆主题弱相关，但它提供了评估代理在线适应、对手建模和长期策略状态的高质量基础设施。

## 2. 怎么做、实验如何设计

平台覆盖完美信息、非完美信息和多人博弈；Chess 采用成对比赛，Poker 每对模型约 20,000 手牌，整体约 31,500 场/局量级，并为狼人杀设计角色与多人排名分解。评测强调固定环境、可复现实行、ground-truth 规则结果和跨版本持续排行榜，而非 LLM judge 偏好。

## 3. Conclusion

动态竞争环境能随着模型增强而自动提高难度，并暴露静态问答看不到的策略脆弱性。论文的主要贡献是评测平台和协议，不是新的 memory 方法。

## 4. Future impact

可以把 agent memory 系统接入同一模型，在重复对局中测量对手记忆、跨局策略迁移与遗忘；比一次性 QA 更适合检验“写入什么、何时更新、何时丢弃”。

## 5. Critical thinking

强项是顶级机构、规模和非主观评分。弱点是游戏胜率混合了基础推理、工具实现、采样方差和 memory 能力，当前平台没有专门操纵记忆。建议增加相同对手的多阶段赛季、隐藏规则漂移、允许/禁止跨局记忆的配对实验，并记录策略变化的因果归因。

## 6. 可信度判断

**4.5/5。** 已阅读全文。基础设施、规模与规则评分可靠；但对用户研究方向属于弱相关启发，不能据此声称模型具有通用长期记忆。
