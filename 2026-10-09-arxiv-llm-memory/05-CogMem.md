# 05｜CogMem：带来源归属的可演化对话记忆

- 论文：[arXiv:2610.11314](https://arxiv.org/abs/2610.11314)；[官方 PDF](https://arxiv.org/pdf/2610.11314)；[本地 PDF](05-CogMem.pdf)。主分类 cs.CL，2026-10-09 公告批次 New submissions；首次提交 2026-10-08（UTC），v1。
- 作者/机构（PDF 首页）：Zirui Liao、Zhengxian Wu、Zhuohong Chen 等；清华大学深圳国际研究生院。
- 机构优先级：S（一流研究型大学）；标签：long-term dialogue memory、graph memory、provenance；相关性：直接；novelty：高。

## 1. 做了什么

CogMem 将长期对话记忆从静态片段库改为 Person–Event–Concept–Claim–Fact 图。主张不能把“某人说的看法”直接压平成事实，必须存说话者、对象、时间及后续更新。

## 2. 怎么做、实验如何设计

对话增量转为有来源的图记录，事件可整合为高层 Fact，相冲突的 Claim 按时间和来源调和。查询时用 LLM 解析意图，再调用锚定、遍历、交集、证据落地四个确定性算子。论文在 LoCoMo 和 LongMemEval 用两种主干与多种检索/图基线比较，拆除 Claim、整合与 agent 搜索做消融，并提供语义坍缩探针。

## 3. 结论

直接证据：Qwen2.5-14B 下多跳 F1 为 48.42%，高于所列最佳记忆基线 42.96%；LongMemEval 总准确率 GPT-4o-mini/Qwen2.5-14B 分别为 68.40%/66.50%。去掉 Claim 后知识更新准确率从 73.08% 降至 56.67%；去掉 agent 搜索，多跳 F1 从 48.42% 降至 22.81%。RoG 用零样本检查点比较，不能解读成优于充分微调的 RoG。

## 4. 未来影响

我的推断：来源归属与操作化检索可成为个人记忆防“错误归因”和多会话推理的基础件；但图增长成本须被持续计量。

## 5. Critical thinking

关键假设是抽取的 Claim/Fact 类型准确、时间归一化可靠。相较一般 GraphRAG，论文把主观陈述与事实分离，并可主动组合图算子。可能失败于间接引语、讽刺、多人共用帐号、时间模糊或图中错误边不断累积。建议用带人工来源标注的长对话、冲突更新和撤回测试，报告图构建 token 费用、延迟、存储及错误传播；拆开“图结构”与“额外 LLM 搜索调用”的贡献。

## 6. 可信度判断

**4/5**。多数据集、多主干和明确组件消融提供较强证据，全文也公开了零样本比较边界；但自动抽取误差、图长期维护及生产成本尚未充分验证。
