# 11｜EFRE：可演化函数库缓解提示式持续学习遗忘

- 论文：[arXiv:2610.11373](https://arxiv.org/abs/2610.11373)；[官方 PDF](https://arxiv.org/pdf/2610.11373)；[本地 PDF](11-EFRE.pdf)。主分类 cs.LG，2026-10-09 公告批次 New submissions；首次提交 2026-10-08（UTC），v1。
- 作者/机构（PDF 首页）：Fengyuan Liu、Yue Wang、Hangxi Guo 等；香港中文大学（深圳）、上海人工智能实验室、中国科学技术大学、新泽西理工学院等。
- 机构优先级：S（一流高校合作）；标签：continual learning、procedural memory、prompt optimization；相关性：直接；novelty：高。

## 1. 做了什么

EFRE 把一个持续增长的优化提示拆成可演化的功能库：新反馈若兼容就更新既有函数，若冲突则生出新函数，以避免顺序任务让单一 prompt 相互覆盖。

## 2. 怎么做、实验如何设计

功能库作为推理时可检索/调用的程序性知识，任务反馈驱动候选修改并进行历史一致性检查。论文先展示普通提示优化在连续适应中遗忘，再在三个顺序任务流及最小 agent 系统中与 GRPO、单一提示优化等基线比较，做机制与消融分析。

## 3. 结论

直接证据：三任务结束时平均表现比 GRPO 高 7.50 个百分点；适应 Bio 任务后 FinQA 性能只降 1.56 点，单一提示优化降 25.10 点。上述数字出自特定三任务顺序，不能说明任意长任务流都稳定。

## 4. 未来影响

我的推断：功能级记忆可比长 prompt 更便于版本管理和冲突隔离，适合持续学习 agent 的技能记忆，但需要检查检索错误与库膨胀。

## 5. Critical thinking

关键假设是任务反馈能区分“兼容更新”与“真正冲突”；若标注噪声大，功能分裂会造成重复技能或错误合并。与常规参数微调或单一 prompt 迭代相比，EFRE 把变化显式分叉。建议随机化任务顺序、扩展到十余任务与非数学领域，报告功能库尺寸、调用延迟及跨任务迁移，加入同预算检索技能库基线。

## 6. 可信度判断

**3/5**。有顺序任务、基线、消融和 agent 实例；任务流仍短，长期库增长及真实环境稳定性未被充分证明。
