# 20｜持久记忆的准入与呈现应分开治理

- 论文：[arXiv:2610.11188](https://arxiv.org/abs/2610.11188)；[官方 PDF](https://arxiv.org/pdf/2610.11188)；[本地 PDF](20-Memory-Governance.pdf)。主分类 cs.AI，2026-10-09 公告批次 New submissions；首次提交 2026-10-08（UTC），v1。
- 作者/机构（PDF 首页）：Chang Liu、Deliang Ding；可直接核验 Chang Liu 标为 Pazhou Laboratory, Guangzhou。Deliang Ding 的个人机构首页未清晰标出，故其机构**未核验**，不据此推断。
- 机构优先级：A（Pazhou Laboratory；较低机构优先级的启发性补充）；标签：personalized memory、memory admission、presentation governance；相关性：直接；novelty：高。

## 1. 做了什么

论文把持久记忆的两种治理决定拆开：哪些召回条目允许进入工作上下文（admission），与进入后应如何措辞（presentation）。关注盲目注入历史导致的迎合、跨领域泄漏及有益个性化受损。

## 2. 怎么做、实验如何设计

无需重新训练，设计条目级 factor-compiled 准入和分解为有类型单位的 permission-semantic 准入，属性经确定性策略变为准入结论。四主干开发集及外部四任务、每任务 300 样本，与原文注入、查询条件门控、相同预算下随机/相关性选择比较；固定准入结论只换呈现方式以分离机制，并做多重比较校正。

## 3. 结论

直接证据：外部基准 pooled judge-assessed 失败率相对原文注入分别降 6.7、8.8 个百分点；更严准入可再降低跨领域失败 17.5 点。仅换两种呈现方式的比较经校正后无显著差别。两种方法都增加个性化失败，PS 未达预注册的改进/个性化保留标准——这是不能省略的负结果。

## 4. 未来影响

我的推断：记忆安全不应仅靠生成时“说得委婉”，更应该在上下文注入之前做许可和领域准入；但过滤强度须和个性化效用共同优化。

## 5. Critical thinking

关键假设是自动判定的记忆属性与许可语义足够准确，且裁判模型能可靠识别迎合/泄漏。论文与简单相关性门控不同，显式分开准入和呈现，却显示安全—效用冲突。建议对真实用户获授权记忆做盲评与撤回测试，报告假拒绝率、用户满意度和不同群体影响；对相同准入集合做人工评估，验证“呈现效应不显著”是否仅为功效不足。
