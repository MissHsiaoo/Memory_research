# 08｜上下文里的奖励真的在教 LLM 吗

- 论文：[arXiv:2610.11152](https://arxiv.org/abs/2610.11152)；[官方 PDF](https://arxiv.org/pdf/2610.11152)；[本地 PDF](08-KAIST-reward-ICL.pdf)。主分类 cs.LG，2026-10-09 公告批次 New submissions；首次提交 2026-10-08（UTC），v1。
- 作者/机构（PDF 首页）：Minchan Kwon、Seunghee Koh、Sunghyun Baek、Minsung Bae、Junmo Kim；KAIST。
- 机构优先级：S；标签：in-context learning、agent memory、in-context RL；相关性：直接；novelty：高。

## 1. 做了什么

论文质疑把“在 prompt 中堆轨迹和奖励后性能上升”直接称作推理时强化学习。它把轨迹、奖励分别扰动，考察奖励是否真的起到学习信号作用。

## 2. 怎么做、实验如何设计

聚焦最直接的 ICRL：模型只读原始轨迹—奖励对，不更新权重。论文在四个基准、六个模型上翻转、随机化或删除奖励，同时打乱、破坏轨迹并控制输入格式；还用鼓励探索/利用的元提示测试模型是否会依奖励调整。

## 3. 结论

直接证据：奖励被模型读取，但这些奖励扰动几乎不改变性能改善曲线；许多轨迹内容破坏也不削弱提升。作者据此将其解释为更接近 ICL 的分布/示例效应，而非真正基于奖励更新的 RL。结论只针对论文限定的直接 ICRL 形式。

## 4. 未来影响

我的推断：agent 记忆评测应加入奖励置乱、轨迹置乱与格式匹配对照，避免把提示长度或分布效应误报成从经验学会策略。

## 5. Critical thinking

关键假设是被测任务能显露奖励语义效应。奖励可能需要结构化反思、外部价值函数或更长探索才能发挥作用；论文并未排除这些机制。建议在固定轨迹、固定 token 量下跨任务翻转奖励极性，直接测下一步策略的方向性变化；加入真实长时程 agent 与更明确的状态转移环境。

## 6. 可信度判断

**4/5**。多模型、多基准和有针对性的反事实扰动支持其有限否定结论；对所有形式的 in-context RL 作普遍否定则证据不足。
