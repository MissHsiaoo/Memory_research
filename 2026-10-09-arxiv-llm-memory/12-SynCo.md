# 12｜SynCo：训练任务与自演化模型协同更新

- 论文：[arXiv:2610.11345](https://arxiv.org/abs/2610.11345)；[官方 PDF](https://arxiv.org/pdf/2610.11345)；[本地 PDF](12-SynCo.pdf)。主分类 cs.AI，2026-10-09 公告批次 New submissions；首次提交 2026-10-08（UTC），v1。
- 作者/机构（PDF 首页）：Wei Yang、Shawn Li、Yuehan Qin 等；南加州大学、乔治华盛顿大学、佐治亚理工学院。
- 机构优先级：S（一流大学）；标签：self-evolving agent、multi-agent RL、experience generation；相关性：**弱相关但具启发性**（演化训练经验而非长期记忆库）；novelty：高。

## 1. 做了什么

SynCo 让任务合成器和解题模型一同进化，针对静态数据很快变得太简单、困难数据又无学习信号的问题。它涉及经验生成/利用的闭环，对自演化记忆研究有训练数据侧启发。

## 2. 怎么做、实验如何设计

两个独立参数化 agent：Synthesizer 根据 Reasoner 当前能力构造任务，Reasoner 在多条 rollout 上学习。正确性奖励更新 Reasoner，任务质量、答案可靠性与可教性反馈更新 Synthesizer，下一轮再生成任务。论文在八个数学推理基准和静态/单独更新/合成数据基线比较，并分析初始不会做的题是否贡献主要增益。

## 3. 结论

直接证据：论文报告八基准的总体优势，以及来自初始未解题的主要增益；结果支持能力边界附近的训练样本比固定任务池更有用。它没有直接验证持久 agent memory，也没有证明生成任务在开放世界可靠。

## 4. 未来影响

我的推断：记忆库也可采用“当前能力缺口→生成诊断经历→验证写入”的循环，而不是只被动收集成功轨迹。

## 5. Critical thinking

关键假设是合成器奖励能同时衡量真实任务价值与答案可信度；数学题的可自动验真性不适用于开放网页。与只更新 learner 的方案相比，训练分布被共同更新。建议迁移到需长期记忆的 agent 时设置独立 held-out 任务与外部验证器，监测自生成任务和自评奖励互相迎合；比较同等训练 token/算力预算。

## 6. 可信度判断

**3/5**。多数学基准及受控基线支持该训练机制，但结论跨向长期记忆与现实 agent 仍是推断；合成任务/自动答案验证可能掩盖闭环偏差。
