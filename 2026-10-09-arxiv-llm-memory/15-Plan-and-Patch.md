# 15｜Plan-and-Patch：扩散语言模型的局部计划修复

- 论文：[arXiv:2610.10786](https://arxiv.org/abs/2610.10786)；[官方 PDF](https://arxiv.org/pdf/2610.10786)；[本地 PDF](15-Plan-and-Patch.pdf)。主分类 cs.AI，2026-10-09 公告批次 New submissions；首次提交 2026-10-07（UTC），v1。
- 作者/机构（PDF 首页）：Syamantak Kumar、Jiang Guo、Hassan Hamad 等；得克萨斯大学奥斯汀分校、Amazon。
- 机构优先级：A+；标签：diffusion LLM、agent planning、局部重写；相关性：直接；novelty：高。

## 1. 做了什么

将扩散语言模型的并行去掩码与局部填空能力用于 agent 计划：环境使部分步骤失效时只修补受影响区域，不重生成整个计划。

## 2. 怎么做、实验如何设计

框架生成程序式计划，在执行反馈触发修复时保持前缀与后缀不变，仅重新填被遮蔽的计划片段。论文比较 DreamReasoner-8B（扩散）与 Qwen3-8B（自回归）在无任务专门训练的 Natural Plan 修复，以及 ALFWorld、TextCraft 任务训练后生成/修复与时延；附录提供更细的测试设置与不确定性。

## 3. 结论

直接证据：Natural Plan 修复成功率扩散 53.7%，自回归 27.0%；任务训练后计划生成成功率相近，而扩散平均生成时延低 39–46%。这不能直接推断所有下游 agent 完成率都提高。

## 4. 未来影响

我的推断：diffusion LLM 更适合需要频繁局部改写的长程计划或工作流记忆，但是否优于高效自回归编辑须在完整闭环验证。

## 5. Critical thinking

关键假设是计划修复区域可准确定位、未修改的前后步骤仍有效。现实工具失败可能改变全局约束；固定后缀反而锁入错误。建议加入错定位、连锁失效及预算受限执行，对比局部 AR 编辑、完整重规划与 dLLM，在同等硬件、训练量和任务成功率上计成本。

## 6. 可信度判断

**3/5**。有两类模型和多任务修复/时延证据；模型架构与训练差异可能混入效应，闭环长期任务及成本仍需更严格匹配。
