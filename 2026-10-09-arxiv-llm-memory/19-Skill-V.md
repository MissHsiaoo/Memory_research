# 19｜Skill-V：可证伪、可修订的 agent 技能库

- 论文：[arXiv:2610.11781](https://arxiv.org/abs/2610.11781)；[官方 PDF](https://arxiv.org/pdf/2610.11781)；[本地 PDF](19-Skill-V.pdf)。主分类 cs.CV，2026-10-09 公告批次 New submissions；首次提交 2026-10-08（UTC），v1。
- 作者/机构（PDF 首页）：Jie Ma、Zhipeng Qian、Yufei Ma 等；厦门大学、Kuaishou Technology、南开大学。
- 机构优先级：A（强研究团队，非指定优先企业）；标签：self-evolving agent memory、skill library、verification；相关性：直接；novelty：高。作为低于 S/A+ 层的启发性补充纳入。

## 1. 做了什么

指出现有自演化技能库偏重新增技能而少重审旧技能。Skill-V 将技能写成带版本、可证伪的契约，在实践结果与契约预测不符时修订适用边界，而非只追加条目。

## 2. 怎么做、实验如何设计

技能契约把语义意图连到可观测行为准则；失败可触发新增，契约—结果不一致可触发边界修订，历史回放与受保护语义约束把关，适用性过滤器剔除确信不适用的技能。论文在 ALFWorld、WebShop 报告成功率、库规模与路由/修订消融。

## 3. 结论

直接证据：ALFWorld 与 WebShop 成功率分别为 95.3% 和 85.9%，库比偏增长的基线更紧凑；过滤减少错误调用，历史回放上的修订未损坏既有结果。历史回放不保证未来无回归。

## 4. 未来影响

我的推断：把长期技能记忆当作可验证软件制品，给每条记忆明确适用条件与回归测试，会比向量相似检索更利于治理。

## 5. Critical thinking

关键假设是环境结果与 rubric 能可靠发现契约边界错误。若任务成功是偶然或 verifier 不完整，版本升级会固化误判。建议随机改动任务分布与工具接口，测被保护约束以外的隐藏回归；给出每次修订的标注/运行成本，与只做适用性过滤的简单基线分开比较。

## 6. 可信度判断

**3/5**。有双基准、规模与组件消融；契约质量、verifier 可靠性和长期未知任务回归仍需独立验证。
