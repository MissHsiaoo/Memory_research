# 01｜REMORY：摘要之外的残差软记忆

- 论文：[arXiv:2610.11287](https://arxiv.org/abs/2610.11287)；[官方 PDF](https://arxiv.org/pdf/2610.11287)；[本地 PDF](01-REMORY.pdf)。主分类 cs.CL，2026-10-09 正式公告批次的 New submissions；首次提交 2026-10-08（UTC），v1。
- 作者/机构（PDF 首页）：Hanchen Xia、Baoyou Chen、Yutang Ge 等；Shanghai Academy of AI for Science、复旦大学、上海交通大学、密歇根大学、香港中文大学、Alibaba Group、南京大学、Shanghai Innovation Institute。
- 机构优先级：S（Alibaba 与一流高校合作）；研究标签：latent memory、上下文压缩、agent memory；相关性：直接；novelty：高。机构层级与下述证据可信度分别判断。

## 1. 做了什么

论文提出 REMORY，在常规文本摘要之后追加有长度上限的连续软记忆 token，补回摘要对后续决策预测遗漏的信息。它不是检索原文的替代，而是摘要与原始档案之外的第三条记忆通道。

## 2. 怎么做、实验如何设计

方法以历史与摘要为输入训练记忆网络，让冻结的 actor 在“摘要＋软 token”条件下尽量接近其看到完整历史时的续写分布；软 token 由摘要条件化。论文在 SummHay 的 92 个问题、10 个文档集合上固定 actor、查询、摘要及解码，比较完整上下文、摘要、等位置预算的文本补充与残差记忆。端到端比较 Qwen3.8-27B 和 GLM-5.3-Flash 在 BrowseComp、Terminal-Bench 2.1 等任务上的有/无软记忆，且保持工具与压缩策略不变；部分任务五次运行，部分只一次。

## 3. 结论

直接证据：SummHay 中引用 F1 提升 4.04 点、联合分数提升 3.55 点，平均输入位置只用完整上下文的 5.2%；Qwen 在 AutomationBench 增 9.8 点、JobBench 增 7.6 点。两种 actor 在 BrowseComp 和 Terminal-Bench 的重复工具输出、错误数均下降。论文也明说成本估计不含特征编码、记忆网络和工具费用，因此不能把生成 token 成本直接当总成本。

## 4. 未来影响

我的推断：若跨模型迁移与总成本仍成立，“文本摘要＋小规模连续残差”可能成为长期 agent 的通用压缩接口，特别适合依赖来源归因的任务。

## 5. Critical thinking

关键假设是完整历史 actor 的预测分布值得模仿，且软记忆能在长任务中稳定保留真正因果相关的细节。相较纯摘要或等预算文本补丁，这里学习的是摘要剩余误差。可能失败于分布外任务、记忆网络与 actor 更换、隐私敏感历史或需要人类可审计证据的场景。建议复现实验：固定完全相同的初始轨迹，分别测摘要、文本补丁、软 token 的首个压缩后决策和实际执行结果；单独计入记忆生成 GPU 时间与能耗，并做跨模型迁移与信息泄露测试。

## 6. 可信度判断

**4/5**。依据是全文提供多基准、等预算对照、固定 actor 的比较与部分重复运行，且明确区分前沿分数与受控对照。局限是部分基准单次运行、若干评分依赖模型裁判，首步反事实只评价动作而不执行；总成本仍未闭环。分数不因机构加成。
