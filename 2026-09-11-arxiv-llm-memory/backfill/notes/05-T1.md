## 1. 做了什么

在真实终端任务上训练能进行数百轮工具调用的 122B-total/10B-active MoE agent。

## 2. 怎么做的，实验怎么做

PPO 加 warm-start critic，使用通过 verifier 的绝对数量提供 dense reward；TITO 保留采样 token IDs、修复回合边界漂移；R3 重放采样时专家路由，缓解训练/推理不一致。

实验与结果：基于 Qwen3.5-122B-A10B，经过 SFT 再用筛选后的 T1-15k RL；Terminal-Bench 2.1 的 89 个任务中 base 43.8%、SFT 49.4%、T1 64.0%。这是 RL 较 SFT +14.6 个百分点，而非 +20.2。同 harness 与跨 harness 榜单分开。平均交互轮数 T1 94.4、SFT 31.5；Hard 组 RL 增益约 3 点。

## 3. Conclusion

工程对齐与 dense reward 对长程 RL 有用，但更高成功率部分伴随更多尝试成本，不代表任意真实生产任务都可靠。

## 4. Future impact

memory agent 训练应保存实际运行上下文、token 边界及路由，而不是对事后重新构造的轨迹直接训练。

## 5. Critical thinking：优点、问题与可验证拓展

优点是公开失败运行、同 harness 对照和系统细节。局限：报告以重复评估中的最佳 checkpoint 为主，应审计独立选点集；OOD 任务不等于对 harness 无适配优势；长交互可能是在低效搜索。建议匹配 token/工具调用预算，比较记忆复用与单纯延长轨迹。可信度 3.5/5。
