# 05｜TeleTune：从离线用户操作记录进化 Agent 技能

- 论文：[arXiv:2610.05437](https://arxiv.org/abs/2610.05437)｜[官方 PDF](https://arxiv.org/pdf/2610.05437)｜本地 `2610.05437.pdf`
- 正式公告：2026-10-06；首次提交：2026-10-04。
- 作者/机构（PDF 首页）：Justin Chih-Yao Chen 等；Microsoft、UNC Chapel Hill、University of Texas at Austin。机构优先级：S；标签：procedural memory、self-evolving agent、offline telemetry；直接相关。

## 1. 做了什么

从没有明确目标、无法重放、还可能混杂多任务的界面操作日志中挖掘文本技能库，而不是依赖人工标注成功轨迹。

## 2. 怎么做、实验如何设计

TeleTune 用已有动作的预测误差提出技能库编辑，只保留在留出日志上提升 skill-guided progress 的修改；测试时还用学到的工作流检索覆盖新任务子目标的示范。PDF 在 WorkArena（含较复杂 L2）与 Online-Mind2Web 对比随机示例检索、Agent Workflow Memory 及组合；作者报告平均成功率 77.1%/80.6%，比各自最强基线高 6.7/7.7 个百分点，并做日志扰动测试。

## 3. 结论

离线遥测可形成可检索程序性记忆，在论文评测中优于既有工作流/检索基线；对新 UI 或真实组织中数据隐私仍无直接保证。

## 4. 未来影响（推断）

个人助理可能从用户实际软件操作中学习偏好的步骤和隐含目标，但需显式同意、隐私隔离和技能版本控制。

## 5. Critical thinking

动作预测准确率只是“模仿过去”，不必然等于任务成功或符合当前用户意图；若日志含错误操作，会形成错误技能。应测用户目标变化、UI 更新、跨用户迁移和敏感操作许可，并用真实成功与安全事件校准代理指标。

## 6. 可信度：4/5

依据：已读 PDF 数据筛选、双基准、扰动和结论。优点是正面处理不可重放日志；局限是离线代理指标与线上长期效益的联系仍需验证。
