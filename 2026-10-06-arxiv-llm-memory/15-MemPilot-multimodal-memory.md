# 15｜MemPilot：按需编排多模态 Agent 记忆整理

- 论文：[arXiv:2610.06830](https://arxiv.org/abs/2610.06830)｜[官方 PDF](https://arxiv.org/pdf/2610.06830)｜本地 `2610.06830.pdf`
- 正式公告：2026-10-06；首次提交：2026-10-05。
- 作者/机构（PDF 首页）：Haozhen Zhang 等；Nanyang Technological University、Tsinghua University、UIUC。机构优先级：A（全球一流高校合作）；标签：multimodal agent memory、memory curation；直接相关。

## 1. 做了什么

把多模态 Agent 的记忆整理视为按需决策：何时用已有查询无关记忆，何时重新整理原始历史。

## 2. 怎么做、实验如何设计

MemPilot 以多步强化学习策略在不同记忆整理动作间选择，调用 LLM/VLM 对原始历史或现成记忆进行整理。PDF 在五个多模态 Agent 记忆基准比较任务成绩、开销和延迟，并报告相应的性能—成本前沿。

## 3. 结论

固定一套记忆压缩流程并非总是最优；按查询和代价选择整理方式在论文基准中更有效。

## 4. 未来影响（推断）

个人助理的记忆可能发展为“编排器 + 多种记忆形态”，在视觉/文本历史、用户隐私成本和实时性之间做动态权衡。

## 5. Critical thinking

强化学习策略是否只记住了基准任务的成本结构？建议测试不同模型价格、长历史增长、模态缺失以及隐私敏感内容，并把错误记忆的下游损害纳入奖励。

## 6. 可信度：4/5

依据：已读 PDF 的策略、五基准与性能/成本比较。优点是同时评估质量和整理代价；局限是线上长期用户记忆及隐私风险未验证。
