# 11｜ForkPilot：学习长程 Agent 何时回溯搜索

- 论文：[arXiv:2610.04889](https://arxiv.org/abs/2610.04889)｜[官方 PDF](https://arxiv.org/pdf/2610.04889)｜本地 `2610.04889.pdf`
- 正式公告：2026-10-06；首次提交：2026-10-04。
- 作者/机构（PDF 首页）：Xinyue Zeng 等；Virginia Tech、Microsoft。机构优先级：S；标签：self-evolving agent、retrospective search；直接相关。

## 1. 做了什么

把长程 Agent 的“何时分叉、回溯、重试”从固定规则转为可学习、可持续更新的控制策略。

## 2. 怎么做、实验如何设计

以 Search Value Dynamics 衡量回溯收益，先从历史轨迹离线训练 ForkPilot 策略，再用执行结果在线更新。PDF 报告六个基准、七组底座模型、九个对照（含生产 harness），同时比较成功率与 token 成本；部分设定最多节省 59.2% token。这里的“最多”不是所有任务平均收益。

## 3. 结论

学习式回溯控制在论文评测中可提高搜索预算利用率；对真实不断变化的任务，策略能否稳健更新仍需长期测量。

## 4. 未来影响（推断）

Agent 记忆系统可保存失败路径的价值估计，而不只保存成功技能；失败经验因此可能指导何时检索、何时重试。

## 5. Critical thinking

离线轨迹可能只覆盖旧策略曾探索的动作，导致对罕见高价值分叉估值不足。应加入分布漂移与 adversarial tool failure，报告搜索计算总成本、误回溯和错误放弃的比例。

## 6. 可信度：4/5

依据：已读 PDF 的策略训练、广泛模型/基准与成本比较。优点是跨底座对照；局限是最优节省数字并非典型值，线上非平稳性未证实。
