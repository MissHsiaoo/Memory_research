# 02｜PrisMem：按能力维度驱动 Agent 记忆自进化

- 论文：[arXiv:2610.06361](https://arxiv.org/abs/2610.06361)｜[官方 PDF](https://arxiv.org/pdf/2610.06361)｜本地 `2610.06361.pdf`
- 正式公告：2026-10-06；首次提交：2026-10-05。
- 作者/机构（PDF 首页）：Yaoqi Chen 等；University of Science and Technology of China、Microsoft、University of California San Diego。机构优先级：S；标签：self-evolving agent memory、可执行记忆程序、长历史；直接相关。

## 1. 做了什么

PrisMem 反对把记忆系统只按总体分数改写：某项能力进步可能被另一项回退掩盖。它按能力维度搜索、诊断、保留候选，再整合互补改进。

## 2. 怎么做、实验如何设计

方法做依赖感知的能力选择、利用历史轨迹诊断的专门改写，以及对比程序在成对差异案例上的行为后做 trace-guided integration。PDF 在 BEAM-100K 和 LongMemEval-S 训练 20 轮，再在内容不同且长达百万 token 的 BEAM-1M、LongMemEval-M 测试；还问进化成本、组件贡献和能力边界。作者报告对最强基线分别高 10.54 与 7.83 个百分点。

## 3. 结论

在所测基准，保留能力级增益并整合比单一总体指标搜索更有效。成绩属于论文直接报告，不等于所有记忆能力都单调改进。

## 4. 未来影响（推断）

记忆系统优化应有能力仪表盘：事实捕获、时间更新、冲突处理、检索、删改等独立门槛；新版本需比较每一项回归。

## 5. Critical thinking

预定义能力划分会决定搜索方向；未标注的隐私、用户偏好漂移可能被忽略。建议跨基准迁移、加入真实删除/更正场景，以及用不可变外部测试集确认整合没有 benchmark-specific 过拟合。百万 token 历史的运行成本也应与收益同时审计。

## 6. 可信度：4/5

依据：已读 PDF 算法、训练/测试拆分、成本与组件问题、结论；强项是跨长度测试及差异案例整合。局限是两个基准和预设能力本体，生产数据效果待复现。
