# 12｜DUET：Solver 与 Grader 协同进化

- 论文：[arXiv:2610.04087](https://arxiv.org/abs/2610.04087)｜[官方 PDF](https://arxiv.org/pdf/2610.04087)｜本地 `2610.04087.pdf`
- 正式公告：2026-10-06；首次提交：2026-10-02。
- 作者/机构（PDF 首页）：Fengyu Gao 等；University of Virginia、Microsoft。机构优先级：S；标签：self-evolving agent、evaluation feedback；**弱相关但具启发性**：不直接研究持久记忆。

## 1. 做了什么

提出求解 Agent 与评分 Agent 轮流改进，使训练反馈也随求解器能力一起进化。

## 2. 怎么做、实验如何设计

DUET 交替优化 solver/grader；PDF 在四个 Agent 任务基准比较固定 grader 与共同进化方案，观察最终任务表现及 grader 反馈质量。论文使用基准内参考评估器，但未把其视为真实人类偏好真值。

## 3. 结论

静态评分器可成为自我提升瓶颈；在所测基准，共同进化优于固定反馈。

## 4. 未来影响（推断）

自进化记忆不应只更新“做法”，还应更新“何种经验值得记住”的判别器；DUET 为此提供了反馈循环启发。

## 5. Critical thinking

solver 与 grader 同时演化易出现相互迎合。应加入独立、冻结的人类或程序验证集，并测多轮后是否奖励黑客化、记忆污染。研究主题关联是上述推断，并非论文直接展示。

## 6. 可信度：3/5

依据：已读 PDF 的优化过程和四基准评估。优点是针对反馈瓶颈；局限是 grader 正确性的外部验证有限，和长期记忆效果无直接实验。
