# 09｜ALoDLM：按 token 难度自适应循环的扩散语言模型

- 论文：[arXiv:2610.04198](https://arxiv.org/abs/2610.04198)｜[官方 PDF](https://arxiv.org/pdf/2610.04198)｜本地 `2610.04198.pdf`
- 正式公告：2026-10-06；首次提交：2026-10-03。
- 作者/机构（PDF 首页）：Liancheng Fang 等；Amazon AGI、University of Illinois Chicago、Korea University。机构优先级：S；标签：diffusion LLM、adaptive computation；直接相关。

## 1. 做了什么

探索扩散语言模型按生成位置自适应分配内部循环计算，避免所有 token 使用相同去噪预算。

## 2. 怎么做、实验如何设计

ALoDLM 在潜在表示中反复执行计算，并为不同 token 决定循环次数。PDF 报告 1.7B、8B 模型及 11 个基准的质量/吞吐比较；作者称 8B 模型在可比准确率下相对 vLLM 上的 Qwen3-8B 约 2.7 倍吞吐。代码和权重链接见 PDF 首页。

## 3. 结论

自适应计算在论文的任务组合上可改善质量—吞吐权衡；作者也指出首 token 延迟更长、吞吐随输入变化，短回复可能没有优势。

## 4. 未来影响（推断）

对扩散 LLM 的关键启示是“推理步骤也应个性化”：难 token 多算、易 token 少算；类似机制可尝试用于记忆读取深度控制。

## 5. Critical thinking

总吞吐和交互体验不是同一指标。应在等价硬件、并发与输出长度分布下独立复测首 token 延迟、尾延迟、功耗和准确率，并排除不同推理栈造成的速度差。
