# 04｜TrajLong：把 Agent 轨迹编成长期上下文训练任务

- 论文：[arXiv:2610.04973](https://arxiv.org/abs/2610.04973)｜[官方 PDF](https://arxiv.org/pdf/2610.04973)｜本地 `2610.04973.pdf`
- 正式公告：2026-10-06；首次提交：2026-10-04。
- 作者/机构（PDF 首页）：Miao Peng 等；Tencent Hunyuan Team、HKUST (Guangzhou)、Peking University。机构优先级：S；标签：long-context、agent memory 能力、轨迹中训练；直接相关。

## 1. 做了什么

TrajLong 认为长 Agent 轨迹的价值不在长度本身，而在其中可训练的原子能力：证据落地、跨证据聚合、时间状态维护。

## 2. 怎么做、实验如何设计

将真实轨迹编译成有密集监督的长上下文任务，再做 mid-training 和 SFT。PDF 用 Qwen3-14B-Base 及 Qwen3-30B-A3B-Base，混合约 30B 背景 token 与 10B 轨迹 token，训练上下文 256K；在六项长上下文和十二项 Agent 基准比较原始/掩码轨迹训练，并做能力级消融。

## 3. 结论

作者报告多数任务改进，且原子能力与下游 Agent 任务存在任务依赖关联。与直接记忆写读系统不同，这是模型预训练能力塑形。

## 4. 未来影响（推断）

长历史 Agent 的基础模型训练可从“喂入更多轨迹”转向“按证据、聚合与状态维护设计监督”，提升其利用外部记忆的底层能力。

## 5. Critical thinking

训练收益可能来自 token 数、数据域或任务格式，而非三种能力分解本身；原始与编译轨迹应严格配平算力与去重。建议以未见真实工具生态、多语言长期用户偏好和状态反转任务验证迁移，防止只在基准模板上提升。

## 6. 可信度：4/5

依据：已查 PDF 两模型规模、训练配比、十二 Agent/六长上下文基准与消融。优点是大规模配平比较；局限是归因到某个原子能力仍主要靠相关与消融，生产收益待验证。
